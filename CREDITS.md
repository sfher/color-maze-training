This is a personal learning project. Development, curriculum planning,
documentation and code review were assisted by OpenAI Codex. The structured
stateful teaching workflow used Matt Pocock's `teach` skill to plan short
lessons, review progress and turn feedback into exercises.

AI assistance does not imply endorsement by OpenAI, Matt Pocock, or any
other named tool author. The project author directed the work and is
responsible for the released game and repository.
