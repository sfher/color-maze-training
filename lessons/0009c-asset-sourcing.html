找素材
不是搜图片

素材查找是需求、授权、来源和导入的组合技能。今天给 HUD 找一套可追溯的字体、图标和音效，并留下能交给团队的来源记录。

60–90 分钟 License · Provenance · Import 产出：可追溯的 UI 素材包

本 Lab 的胜利条件

先写需求，再打开搜索

直接搜“像素素材”会得到一堆风格、比例和授权都不一致的东西。先写一张小规格表：

素材需求硬性约束
字体像素风 UI 字体，适合 12–28 px必须覆盖 HUD 中实际出现的字符；确认许可允许游戏内嵌入
图标 2 个炸弹、材料/宝箱，透明背景64×64 或整数倍；风格一致；CC0 或 CC BY
音效 1 个短促的拾取/开箱声WAV/OGG；时长短；来源与许可清晰
整体像素、明亮、未来/治愈颜色数量克制；不抢功能方块的辨识度
中文字体先查字形覆盖

很多英文像素字体没有中文字形。UI 里写中文时，先确认字体包含需要显示的汉字；如果找不到合适字体，暂时保留 TMP 默认字体，只替换图标和音效。不要用一个只有拉丁字母的字体硬套中文。

高信任素材源

UI / 像素素材

  • Kenney Assets：大量 CC0 素材，适合原型；仍需逐包核对许可。
  • OpenGameArt：授权混合，必须逐个素材看许可证。
  • itch.io Free Assets：质量高但授权差异大，只看明确标注。
  • Game-icons.net：图标常用 CC BY 3.0，通常需要署名。

字体 / 音频 / 3D

  • Google Fonts：多为 OFL，先查字体许可和字形覆盖。
  • Freesound：按 CC0/CC BY 筛选，逐条看音频许可。
  • Poly Haven：3D 环境素材，常见 CC0。
  • Quaternius：低多边形 3D，常见 CC0，逐包核对。

Unity Asset Store 的素材也可以使用，但它受 Asset Store EULA 约束，通常不等于可以随意转载或重新分发原始文件；使用前读许可页面。

关键词怎么搜：三轮查询法

搜索不到，通常不是“素材不存在”，而是查询词太抽象。把需求拆成四段：

对象/动作 + 风格 + 载体/格式 + 用途

例：coin + 8-bit + ogg + pickup
例：pixel font + simplified chinese + ttf + HUD
例：stone break + retro + wav + bomb impact

搜索卡住时的三个动作

换同义词（如 pickup / collect / coin / reward）；换载体词（sfx / sound / audio / ui）；换需求（“必须像某游戏”改成“短促、明亮、无混响”）。如果两轮都没有结果，换来源或改需求，不要继续刷新同一页。

本项目已经准备好一份音效搜索 brief：Color Maze/docs/AUDIO_SEARCH.md。先用它挑一个拾取音效，不要一次找完整套音频。

目前项目里已经放入一套可直接试听的 Kenney CC0 starter set：8 个短音效，位于 Assets/ThirdParty/Audio/Kenney/，并保留了三份原始许可。先试听并选择是否采用，不要因为“已经下载”就默认全部接入。

许可证先看，不要先下载

许可证常见含义你需要做什么
CC0放弃版权，通常可商用和修改仍记录来源，方便追溯
CC BY 4.0可商用/修改，但必须署名保留作者、标题、来源、许可链接和修改说明
OFL 1.1常见字体许可，可随游戏嵌入保留版权与许可文本；确认字体是否覆盖所需字形
MIT常见代码许可保留版权与许可声明
Asset Store EULA在项目中使用，不等于可重新分发原始素材读具体许可，不把原始包当素材库分享
“免费下载”不是许可证没有明确许可就不使用
重要边界

这里不是法律意见。许可证原文优先；商用、修改、再分发、署名方式有疑问时，选择更明确的素材，或向作者确认。拿不准就不要用。

01

比较两个来源

对每类素材至少看两个来源，用这个评分表做选择：

维度要问的问题
授权许可证明确吗？允许商用和修改吗？需要署名吗？
风格和现有颜色、分辨率、像素比例一致吗？
字形/内容字体是否覆盖中文？图标是否有透明背景？音频是否干净？
技术格式能导入 Unity 吗？文件尺寸合理吗？命名是否清楚？
维护来源稳定吗？作者是否明确？许可文件是否随包提供？

“看起来最酷”排在最后。先过授权和技术约束，再比较美术偏好。

02

建立可追溯的来源记录

在 Color Maze/THIRD_PARTY_NOTICES.md 创建记录。可以从这个模板开始：

THIRD_PARTY_NOTICES.md
# Third-Party Notices

| ID | Asset | Author | Source | License | Date | Modified | Attribution |
|---|---|---|---|---|---|---|---|
| UI-Font-01 | ... | ... | ... | OFL 1.1 | 2026-10-21 | No | ... |
| UI-Icon-01 | ... | ... | ... | CC0 | 2026-10-21 | Recolored | Not required |

## License Texts

Place the original license files or links here.

## Notes

- Asset folder: Assets/ThirdParty/...
- Changes: ...
- Questions: ...

素材放在 Assets/ThirdParty/<PackName>/，原始 LICENSE / README 不要删。改名要记录；同一素材的不同版本也要能追溯。

03

导入 Unity 的检查清单

2D / UI 图标

  • Texture Type：Sprite (2D and UI)。
  • 像素风：Filter Mode Point，Compression None，Generate Mip Maps 关闭。
  • 确认 Pixels Per Unit 与项目格子一致；UI Image 勾选 Preserve Aspect。

字体

  • 先确认中文字形覆盖，再创建 TMP Font Asset。
  • 保留原始字体文件和 OFL 文本；不要只留下生成的 Atlas。
  • 字形不够时使用动态字体或换字体，不要用缺字字体硬做。

音效

  • 短音效优先 WAV；确认采样率、声道和响度。
  • 在 AudioSource 上实际试听，避免爆音或过长。
  • 记录来源和许可，不把素材包原始文件散落到多个目录。
04

实际使用一项素材

选择至少一项落到游戏里：

  • 把 UI 图标用在炸弹/材料/宝箱的数字旁边，或做成道具栏。
  • 把确认支持中文的像素字体用于 HUD；若字体不支持中文，保留默认字体。
  • 把短音效接到拾取或开箱事件上（音效系统还未做时，先记录到下一步）。

不要只把文件拖进项目就算完成。素材必须被场景或预制体实际引用，才能验证导入设置、尺寸和视觉效果。

AI 生成素材的处理

AI 生成素材不是自动禁用，也不是自动可用。使用前要确认工具条款、商用许可、是否允许修改，并记录工具、提示词和日期。不要生成/使用模仿受版权保护角色、真实人物肖像或声音克隆的内容。对“来源不明”的 AI 资源，按“无许可素材”处理。

一条团队规则

任何外部素材进入项目，都必须同时进入来源记录。没有记录，就等于未来无法安全发布。

检索练习

先不要往上翻。

1. CC BY 素材通常需要你做什么？

CC BY 允许使用和修改，但必须按许可要求署名、标明来源和修改。

2. “免费下载”通常意味着什么？

免费不等于授权明确；能否商用、修改、再分发必须看许可证原文。

3. 中文像素字体选型要先确认什么？

字形覆盖是硬约束；字体再好看，缺字也无法完成中文界面。

4. 外部素材应该放在哪并留下什么？

集中放在 ThirdParty，保留许可并在 THIRD_PARTY_NOTICES.md 记录来源和修改。

素材工作流急救

问题处理
找不到中文字体保留默认字体，先替换图标/音效；不要用缺字字体。
图标糊Point Filter、关闭压缩、确认 PPU 和尺寸。
许可看不懂查原文、作者 FAQ；仍不确定就换素材。
来源页消失保存标题、作者、下载日期和许可文本快照。
素材风格不统一先定调色板/像素比例，再筛选；不要混多个包。
提交后无法发布回查 notices、许可原文和素材引用关系。
