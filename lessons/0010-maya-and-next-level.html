完成一关后，玩家要回到 MAYA 身边，得到下一条线索，再进入下一关。今天把关卡引用、跨场景选择和“下一关”按钮串起来。

50–70 分钟 ScriptableObject · GameSession · 场景流 产出：MAYA 线索与下一关

本课胜利条件

为什么不能只写 nextLevel

场景重载时，场景里的组件会重建，Maze 的 Level 字段会回到 Inspector 中保存的那个关卡。只在 LevelDefinition 里写一个 NextLevel，还不足以让新关卡被加载。

本课用一个小小的跨场景选择器：

LevelDefinition.NextLevel
        ↓
GameSession.CurrentLevel（静态，跨场景重载保留）
        ↓
SceneManager.LoadScene
        ↓
MazeBootstrapper.Awake 读取 CurrentLevel
        ↓
重新生成新关卡
这不是存档系统

GameSession 只在本次运行中保存当前关卡；停止 Play 或重新启动游戏后清空。真正的进度存档会在后面的存档课用文件/JSON 完成。

01

让关卡指向下一关

打开 LevelDefinition.cs，在 rows 下面加入：

LevelDefinition.cs
[SerializeField] private LevelDefinition nextLevel;

public LevelDefinition NextLevel => nextLevel;

这样每个关卡资产都能在 Inspector 中指定下一关，而不是把流程写死在代码里。最后一关的 NextLevel 留空。

02

创建 GameSession

新建 GameSession.cs：

GameSession.cs
public static class GameSession
{
    public static LevelDefinition CurrentLevel { get; set; }

    [UnityEngine.RuntimeInitializeOnLoadMethod(
        UnityEngine.RuntimeInitializeLoadType.SubsystemRegistration)]
    private static void ResetOnPlay()
    {
        CurrentLevel = null;
    }
}

SubsystemRegistration 在每次进入 Play 时清空 CurrentLevel；场景重载不会触发它，所以下一关/重开能保持当前关卡。

03

让 Maze 从 GameSession 选关卡

在 MazeBootstrapper 加入 Awake 和当前关卡属性：

MazeBootstrapper.cs
public LevelDefinition CurrentLevel => level;

private void Awake()
{
    if (GameSession.CurrentLevel != null)
    {
        level = GameSession.CurrentLevel;
    }
    else
    {
        GameSession.CurrentLevel = level;
    }
}

第一次启动使用 Inspector 里保存的初始 Level；下一关重载时使用 GameSession 里保存的关卡。Start 之后仍然照常生成格子。

04

让流程控制器切换到下一关

给 LevelFlowController 增加 Maze 引用：

LevelFlowController.cs · 字段
[SerializeField] private MazeBootstrapper maze;

加入判断和切换方法：

LevelFlowController.cs · 下一关
public bool CanAdvance =>
    State == LevelState.Completed &&
    maze != null &&
    maze.CurrentLevel != null &&
    maze.CurrentLevel.NextLevel != null;

public void AdvanceToNextLevel()
{
    if (!CanAdvance)
    {
        return;
    }

    LevelDefinition next = maze.CurrentLevel.NextLevel;
    audio.PlayUiConfirm();
    GameSession.CurrentLevel = next;
    Time.timeScale = 1f;
    SceneManager.LoadScene(
        SceneManager.GetActiveScene().buildIndex);
}

Start 的引用校验也要包含 Maze：playerStats == null || audio == null || maze == null。完整参考：solutions/0013/LevelFlowController.cs。

05

在结算面板加“下一关”

在 EndPanel 中增加一个 Button，命名为 NextLevelButton，文案“下一关”。它和原来的“重开”并列。

给 GameHud 增加字段：

GameHud.cs · 字段与绑定
[SerializeField] private Button nextLevelButton;

nextLevelButton.onClick.AddListener(
    flow.AdvanceToNextLevel);

// OnDestroy
nextLevelButton.onClick.RemoveListener(
    flow.AdvanceToNextLevel);

状态变化时控制显示，并写 MAYA 的台词：

GameHud.cs · 完成状态
bool canAdvance =
    flow.State == LevelState.Completed &&
    flow.CanAdvance;

nextLevelButton.gameObject.SetActive(canAdvance);

endHintText.text =
    flow.State == LevelState.Completed
        ? (canAdvance
            ? "MAYA：我找到下一条线索了。"
            : "MAYA：这次的材料够了，旅程暂告一段落。")
        : "按 R 或按钮重开。";

失败时 canAdvance 为 false，下一关按钮隐藏；重开按钮仍保留。完整参考：solutions/0013/GameHud.cs。

07

让镜头适应关卡尺寸

关卡数据换了，画面尺寸也可能换。当前相机正交尺寸是 5，只能完整显示 10 个世界单位的高度；Level_05 有 15 行，如果沿用旧设置，顶部出口会被裁掉。

新增 MazeCameraFitter，每帧读取当前关卡的宽高。正交相机同时受垂直尺寸和窗口宽高比限制，所以两种要求都要计算，再取较大值：

MazeCameraFitter.cs · 核心计算
float halfWidth = level.Width * 0.5f;
float halfHeight = level.Height * 0.5f;

float sizeForHeight = halfHeight + padding;
float sizeForWidth =
    (halfWidth + padding) / _camera.aspect;

_camera.orthographicSize = Mathf.Max(
    minimumSize,
    sizeForHeight,
    sizeForWidth);

把组件挂到 Main Camera，绑定场景中的 Maze。完整实现：MazeCameraFitter.cs。LateUpdate 在关卡切换和 Game 视图比例变化后仍会重新适配。

为什么取最大值

垂直方向至少容纳地图高度，水平方向至少容纳地图宽度。两个约束同时满足时，正交尺寸必须取较大的那个。

08

测试跨场景流程

  1. Play 当前 Level_FlowTest，拿材料到出口：结算显示 MAYA 台词和“下一关”。
  2. 点击“下一关”：场景重载，Maze 生成 Level_05，HUD 资源重置，整个地图与出口进入镜头。
  3. 在 Level_05 暂停后点重开：仍然加载 Level_05，而不是跳回 Level_FlowTest。
  4. 完成 Level_05：没有 NextLevel，下一关按钮隐藏，MAYA 显示旅程暂告一段落。
  5. 失败：下一关按钮隐藏，R/重开留在当前关。
  6. 停止 Play 再重新 Play：GameSession 清空，回到 Inspector 里设置的初始 Level_FlowTest。
如果下一关没切换

依次检查：LevelDefinition.NextLevel 是否绑定、LevelFlowController.Maze 是否绑定、GameSession 是否被其他代码覆盖、Main 是否在 Build Profiles 场景列表。地图显示不全时，再检查 MazeCameraFitter 的 Maze 引用。

检索练习

先不要往上翻。

1. 为什么场景重载后还需要 GameSession？

场景重载会重建对象；静态 GameSession 让后续场景仍知道当前 LevelDefinition。

2. 最后一关没有 NextLevel 时应该怎样？

CanAdvance 为 false，UI 显示旅程暂告一段落，不提供下一关入口。

3. GameSession 与正式存档的区别是什么？

它只解决场景重载时的当前关卡选择；持久化要在后面的存档课实现。

4. 下一关按钮应该在哪里可见？

只有 Completed 且 CanAdvance 时才显示下一关；失败和暂停不显示。

报错急救

现象处理
下一关按钮不出现LevelDefinition.NextLevel 是否绑定，State 是否 Completed。
点击后回到原关GameSession.CurrentLevel 是否在 reload 前赋值。

最后一关仍显示按钮CanAdvance 的 NextLevel 检查是否漏了。
