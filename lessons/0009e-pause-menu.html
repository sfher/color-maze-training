暂停不是
把游戏关掉

暂停是关卡的一个正式状态：时间停住、玩家不能移动、界面显示，但仍然可以继续或重开。今天把 Esc 和按钮接成完整的暂停流程。

45–60 分钟 状态 · timeScale · 暂停 UI 产出：可继续/重开的暂停菜单

本课胜利条件

暂停到底改变了什么

对象暂停时恢复时
LevelStatePausedPlaying
Time.timeScale01
玩家移动停止（flow.IsPlaying 为 false）恢复
暂停面板显示隐藏
AudioListener / 短音效本课不暂停继续使用
timeScale = 0 不会停掉 Update

物理和基于时间的动画会停，但 Update 仍会执行。所以 Esc 检测还能工作；同时 PlayerGridMover 必须继续检查 flow.IsPlaying，否则暂停时仍可能移动。

01

把 Paused 加入关卡状态

修改 LevelState.cs：

LevelState.cs
public enum LevelState
{
    Playing,
    Paused,
    Completed,
    Failed
}

Paused 不是 Completed 或 Failed；暂停后仍然可以回到 Playing。

02

给 LevelFlowController 加暂停

用参考实现替换 LevelFlowController.cs，或加入以下方法：

LevelFlowController.cs · 暂停接口
public void TogglePause()
{
    if (State == LevelState.Playing)
    {
        audio.PlayUiConfirm();
        SetState(LevelState.Paused);
        Time.timeScale = 0f;
        return;
    }

    if (State == LevelState.Paused)
    {
        Resume();
    }
}

public void Resume()
{
    if (State != LevelState.Paused)
        return;

    audio.PlayUiConfirm();
    SetState(LevelState.Playing);
    Time.timeScale = 1f;
}

public void Restart()
{
    Time.timeScale = 1f;
    SceneManager.LoadScene(
        SceneManager.GetActiveScene().buildIndex);
}

在 Update 里处理 Esc，但仍只允许 Playing/Paused 切换：

LevelFlowController.cs · 输入
if (keyboard != null &&
    keyboard.escapeKey.wasPressedThisFrame &&
    (State == LevelState.Playing ||
     State == LevelState.Paused))
{
    TogglePause();
    return;
}

完整参考：solutions/0012/LevelFlowController.cs。注意 Start 和 Restart 都把 timeScale 设为 1，避免暂停后重开仍然冻结。

03

创建暂停面板

  1. 在 Canvas 下创建 Panel，命名为 PausePanel；居中，大小约 520 × 320。
  2. 加入标题 TextMeshPro：暂停，约 44 号。
  3. 加入两个 Button：ResumeButton 文案“继续”，PauseRestartButton 文案“重开”。
  4. 把 PausePanel 设为未激活；运行时由 GameHud 控制。
  5. 确保 EventSystem 存在，按钮才能接收点击。

层级建议：

GameUI (Canvas)
├── StatsPanel
├── EndPanel
├── PausePanel
│   ├── PauseTitle
│   ├── ResumeButton
│   └── PauseRestartButton
└── HintText
04

让 GameHud 管理暂停面板

给 GameHud 增加三个字段：

GameHud.cs · 字段
[SerializeField] private GameObject pausePanel;
[SerializeField] private Button resumeButton;
[SerializeField] private Button pauseRestartButton;

Start 里绑定按钮：

GameHud.cs · 绑定
resumeButton.onClick.AddListener(flow.Resume);
pauseRestartButton.onClick.AddListener(flow.Restart);
pausePanel.SetActive(false);

状态变化时，暂停面板只在 Paused 显示：

GameHud.cs · 状态显示
pausePanel.SetActive(flow.State == LevelState.Paused);

bool ended =
    flow.State == LevelState.Completed ||
    flow.State == LevelState.Failed;
endPanel.SetActive(ended);

完整参考：solutions/0012/GameHud.cs。在 OnDestroy 里也要移除两个按钮的监听，和现有重开按钮一样。

AudioManager 已经绑定 ui_confirm.ogg；暂停和继续都会通过 PlayUiConfirm() 发出确认音。短音效不受 timeScale 影响，仍能播放。

06

测试状态转换

  1. Playing 按 Esc：显示暂停面板，timeScale 变为 0，玩家不能移动。
  2. 再按 Esc 或点“继续”：面板隐藏，timeScale 回到 1，玩家恢复移动。
  3. 暂停时点“重开”：场景重载，timeScale 为 1，玩家与 HUD 回到初始状态。
  4. Completed/Failed 时按 Esc：不应进入暂停；结算面板保持。
  5. 暂停时确认没有移动、没有炸弹、没有重复计时。
  6. 每次暂停/继续都能听到同一个确认音，不会叠成爆音。
如果重开后仍冻结

检查 Restart() 是否先执行 Time.timeScale = 1f，以及新场景的 LevelFlowController.Start 是否也恢复为 1。

检索练习

先不要往上翻。

1. 暂停时为什么还要检查 flow.IsPlaying？

timeScale=0 不会停止 Update；移动脚本必须读取流程状态。

2. 恢复游戏时 timeScale 应该设为什么？

Resume 和 Restart 都必须恢复 Time.timeScale = 1。

3. 结算状态时按 Esc 应该怎样？

只有 Playing/Paused 能切换暂停；Completed/Failed 使用结算面板和 R/重开。

4. 暂停和继续音效应该调用哪个方法？

UI 确认音用于暂停/继续；过关音只用于关卡完成。

报错急救

现象处理
Esc 没反应Game 视图焦点；Input System 中 Escape 键；Flow 是否启用。
暂停后玩家还能动PlayerGridMover 是否检查 !flow.IsPlaying。
重开后仍冻结Restart 和新场景 Start 都把 timeScale 设为 1。
按钮没反应EventSystem；Button 的 OnClick 由 GameHud 绑定。
暂停面板不显示PausePanel 是否绑定，HandleStateChanged 是否在 Paused 分支。
过关/失败时能暂停Esc 状态判断只允许 Playing/Paused。
