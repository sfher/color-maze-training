色彩迷宫 · 开发实训 / 课程 09

把调试 HUD
换成真正的界面

生命、氧气、炸弹现在还是 OnGUI 画出来的调试信息。今天用 Canvas + TextMeshPro 做正式 HUD，并让界面只订阅状态，不拥有状态。

75–90 分钟 Canvas · TextMeshPro · UI 事件 产出：正式 HUD 与结算面板

本课胜利条件

UI 是状态的观察者

正式 UI 不应该拥有生命值，也不应该每帧偷偷改金币。它只做一件事：订阅状态变化，然后把状态翻译成文字和面板。

State

PlayerStats / Flow

保存生命、资源、材料，以及关卡是 Playing、Completed 还是 Failed。

Event

StatsChanged / StateChanged

状态变化时发出通知；UI 收到后刷新。UI 不需要知道规则细节。

View

Canvas / TMP

只负责布局、文字和按钮。以后换成像素字体或动画，不需要改玩法代码。

移除旧 OnGUI

PlayerStats 和 LevelFlowController 现在都用 OnGUI 画字。如果不移除，新 Canvas 会和旧调试层叠在一起，出现两套 HUD。

00

创建 Canvas 与左上角状态面板

  1. 菜单 GameObject → UI → Canvas，命名为 GameUI。
  2. 在 Canvas Scaler 上设置 Scale With Screen Size，Reference Resolution 1920 × 1080，Match 0.5。
  3. 右键 Canvas → UI → Panel，命名为 StatsPanel；锚点设为左上，Position (32, -32)，大小 420 × 340。
  4. 把 Panel 的 Image Color 设为深色半透明，例如 RGBA (0.08, 0.10, 0.12, 0.85)。
  5. 右键 StatsPanel → UI → Text - TextMeshPro，命名为 StatsText；四边拉伸，留 24 的边距；Font Size 28，颜色接近白色，Alignment 左上。
  6. 如果 Unity 弹出 TMP Essentials 导入提示，点 Import TMP Essentials。

Text 内容先随便填；运行时 GameHud 会覆盖成实际状态。一个多行 Text 足够显示五项资源，不需要五个独立 Text。

01

创建完成/失败面板与提示

  1. 右键 Canvas → UI → Panel，命名为 EndPanel；居中，大小 620 × 340，深色背景。
  2. 在 EndPanel 内创建两个 TextMeshPro：EndTitleText（44 号、加粗、居中）和 EndHintText（24 号、居中）。
  3. 右键 EndPanel → UI → Button - TextMeshPro，命名为 RestartButton；大小 200 × 56，按钮文字改成“重开”。
  4. 在 Canvas 下创建 TextMeshPro，命名为 HintText；底部居中，大小约 720 × 50，Font Size 26，颜色淡黄。
  5. 把 EndPanel 和 HintText 的 GameObject 先设为未激活；GameHud 会在需要时打开。
按钮点击需要 EventSystem

创建 UI Button 时 Unity 通常会自动创建 EventSystem。如果点击无效，检查场景里是否有 EventSystem，以及它使用的是不是 Input System UI Input Module。

02

让 PlayerStats 发出状态变化

打开 PlayerStats.cs，加入事件：

PlayerStats.cs
public event System.Action StatsChanged;

// 在 ApplyTile 末尾
StatsChanged?.Invoke();

// 在 TryConsumeBomb、AddBombs、AddCoins、
// AddMaterial 的修改完成后也调用
StatsChanged?.Invoke();

然后删除 GUIStyle _labelStyle 和整个 OnGUI() 方法。建议直接用参考文件整份替换，避免漏删：solutions/0010/PlayerStats.cs。

StatsChanged 不负责具体显示什么，只负责说“数值变了”。HUD 收到后再拼字符串。

03

让 LevelFlowController 发出状态与提示

把 LevelFlowController.cs 整份替换为 参考实现。关键变化：

LevelFlowController.cs · 新接口
public event System.Action StateChanged;
public event System.Action<string> HintShown;

public void ReachExit(bool hasMaterial)
{
    if (State != LevelState.Playing)
        return;

    if (hasMaterial)
    {
        SetState(LevelState.Completed);
        return;
    }

    HintShown?.Invoke("还需要找到材料。");
}

public void Restart()
{
    SceneManager.LoadScene(
        SceneManager.GetActiveScene().buildIndex);
}

删除原来的 OnGUI、GUIStyle 和提示计时字段；提示交给 HUD。R 快捷键仍保留，按钮点击则调用 Restart()。

04

创建 GameHud.cs

在 Assets/Scripts 新建 C# 脚本 GameHud，替换为：

GameHud.cs
using System.Collections;
using TMPro;
using UnityEngine;
using UnityEngine.UI;

public class GameHud : MonoBehaviour
{
    [SerializeField] private PlayerStats playerStats;
    [SerializeField] private LevelFlowController flow;
    [SerializeField] private TMP_Text statsText;
    [SerializeField] private TMP_Text hintText;
    [SerializeField] private GameObject endPanel;
    [SerializeField] private TMP_Text endTitleText;
    [SerializeField] private TMP_Text endHintText;
    [SerializeField] private Button restartButton;

    private Coroutine _hintRoutine;

    private void Start()
    {
        if (!ValidateReferences())
        {
            enabled = false;
            return;
        }

        playerStats.StatsChanged += RefreshStats;
        flow.StateChanged += HandleStateChanged;
        flow.HintShown += ShowHint;
        restartButton.onClick.AddListener(flow.Restart);

        endPanel.SetActive(false);
        hintText.gameObject.SetActive(false);

        RefreshStats();
        HandleStateChanged();
    }

    private void OnDestroy()
    {
        if (playerStats != null)
        {
            playerStats.StatsChanged -= RefreshStats;
        }

        if (flow != null)
        {
            flow.StateChanged -= HandleStateChanged;
            flow.HintShown -= ShowHint;
        }

        if (restartButton != null && flow != null)
        {
            restartButton.onClick.RemoveListener(flow.Restart);
        }
    }

    private bool ValidateReferences()
    {
        if (playerStats == null || flow == null ||
            statsText == null || hintText == null ||
            endPanel == null || endTitleText == null ||
            endHintText == null || restartButton == null)
        {
            Debug.LogError(
                "GameHud: 有引用没有绑定，请检查 Inspector。",
                this);
            return false;
        }

        return true;
    }

    private void RefreshStats()
    {
        statsText.text =
            $"生命  {playerStats.Health} / {PlayerStats.MaxHealth}\n" +
            $"氧气  {playerStats.Oxygen} / {PlayerStats.MaxOxygen}\n" +
            $"炸弹  {playerStats.Bombs}\n" +
            $"金币  {playerStats.Coins}\n" +
            $"材料  {playerStats.Materials} / 1";
    }

    private void HandleStateChanged()
    {
        bool ended =
            flow.State == LevelState.Completed ||
            flow.State == LevelState.Failed;

        endPanel.SetActive(ended);

        if (!ended)
        {
            return;
        }

        endTitleText.text =
            flow.State == LevelState.Completed
                ? "关卡完成"
                : "生命耗尽";

        endHintText.text =
            flow.State == LevelState.Completed
                ? "你找到了材料。"
                : "按 R 或按钮重开。";
    }

    private void ShowHint(string message)
    {
        if (_hintRoutine != null)
        {
            StopCoroutine(_hintRoutine);
        }

        _hintRoutine = StartCoroutine(HintRoutine(message));
    }

    private IEnumerator HintRoutine(string message)
    {
        hintText.text = message;
        hintText.gameObject.SetActive(true);
        yield return new WaitForSecondsRealtime(2f);
        hintText.gameObject.SetActive(false);
        _hintRoutine = null;
    }
}

06

测试正式 HUD

  1. Play：左上角显示生命、氧气、炸弹、金币、材料，旧 OnGUI 不应再出现。
  2. 踩岩浆/水、开宝箱、拿材料：数值即时更新。
  3. 没材料进出口：底部出现 2 秒提示，玩家仍能移动。
  4. 有材料进出口：EndPanel 显示“关卡完成”。
  5. 生命归零：EndPanel 显示“生命耗尽”。
  6. 点击“重开”或按 R：场景重载，HUD 恢复 3/3、0 金币、0 材料。
  7. 改变 Game 视图比例：面板仍保持左上/居中布局。
先看 Console

GameHud 的 ValidateReferences 会明确告诉你哪个引用为空。按钮无效先查 EventSystem，文字不可见先查 TMP 字体材质、颜色和 Canvas 层级。

检索练习：合上资料再答

先不要往上翻。答错没关系，努力回忆本身就在加固记忆。

1. 为什么 UI 不直接修改生命值？

生命状态归 PlayerStats；UI 只观察和显示，避免出现两个互相改数值的来源。

2. 为什么必须移除旧的 OnGUI？

旧 OnGUI 和新 Canvas 会同时绘制同一份状态，形成重复 HUD 或重叠覆盖层。

3. Canvas Scaler 的参考分辨率有什么用？

参考分辨率配合 Scale With Screen Size，让不同窗口尺寸下 UI 按比例缩放。

4. Restart 按钮应该调用什么？

按钮只发出意图，真正的场景重载由 LevelFlowController.Restart 统一处理。
