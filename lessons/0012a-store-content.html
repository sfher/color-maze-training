先把货架装满

金币的价值来自它买到的内容。先完成可购买的主题、图片与关卡目录；商店代码暂缓，避免先做完交易系统却没有值得购买的东西。

30–45 分钟 Content Catalog · Licensing 产出：可购买内容清单

本课胜利条件

当前进度

Level_Water World 已登记为 data-ready：关卡数据已经存在，购买逻辑与预览素材留到后续商店和素材课。

先回答“买了以后多什么”

玩家必须能看见购买后的具体变化。先选少量候选，不设计完整商城。

THEME

UI 主题

HUD 边框、按钮配色与面板皮肤。

GALLERY

画廊图片

MAYA、场景或故事插画，提供收藏目标。

LEVEL

额外关卡

真正能进入并完成的新关卡数据。

01

建立内容目录

Assets/Content/
  UIThemes/
  Gallery/
  Levels/

先统一目录与命名，再制作内容。本课不写商店脚本。

02

使用稳定 ID

每项内容使用稳定、短小、只含英文与连字符的 ID：

theme-terminal-green
image-maya-first-meeting
level-forest-01

显示名称可以改；未来存档只认 ID。

03

填写内容目录

复制模板：STORE-CONTENT-CATALOG.md。

字段通过标准
ID / 名称唯一 ID，玩家能看懂销售名称。
类型Theme、Gallery 或 Level。
预览商店实际可显示的缩略图或色板。
获得后变化一句可验证描述。
来源 / 许可证原创或第三方素材的明确记录。
状态idea、draft、ready；只有 ready 可出售。
04

完成三件候选

  1. 一个 UI 主题：色板和至少一个 HUD 应用示例。
  2. 一张画廊图片：缩略图、来源和许可。
  3. 一个额外关卡：地图、材料位置、出口与公平性说明。

正式素材不足时可以标成 draft；未授权内容不能标成 ready。

05

写验收条件

每项内容都要回答“购买后如何确认真的获得”：

  • 主题：选择后 HUD 立即变化，并在重开后保留。
  • 图片：画廊中出现缩略图，点击可打开完整图片。
  • 关卡：从入口进入，尺寸正确，能拿材料并到达出口。
