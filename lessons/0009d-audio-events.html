色彩迷宫 · 开发实训 / 课程 09d

事件发生了
声音才该响

音效不是背景音乐，也不是每帧播放。今天把拾取、开箱、破石、传送、受伤和过关接到明确的游戏事件上。

45–60 分钟 AudioSource · 事件 · PlayOneShot 产出：8 个可触发音效

本课胜利条件

声音属于事件，不属于帧

如果每帧调用 PlayOneShot，同一个音效会叠加几百次，听起来像爆音。正确做法是：在状态真正改变的那一刻播放一次。

游戏事件播放方法音频文件
拾取材料/金币PlayPickup()pickup_material.ogg
打开宝箱PlayChestOpen()chest_open.ogg
炸开石头PlayStoneBreak()stone_break.ogg
进入传送门PlayPortal()portal_enter.ogg
无材料出口/无效操作PlayUiError()ui_error.ogg
关卡完成PlayLevelComplete()level_complete.ogg
受伤/死亡PlayDamage()damage.ogg
按钮确认（后续）PlayUiConfirm()ui_confirm.ogg
PlayOneShot

AudioSource.PlayOneShot(clip) 可以叠加短音效；Play() 会打断当前播放。拾取和爆炸很适合 OneShot，背景音乐则应该用独立的 AudioSource 和循环播放。

01

完成 AudioManager

替换你当前空的 AudioManager.cs：

AudioManager.cs
using UnityEngine;

public class AudioManager : MonoBehaviour
{
    [SerializeField] private AudioSource source;
    [SerializeField] private AudioClip pickup;
    [SerializeField] private AudioClip chestOpen;
    [SerializeField] private AudioClip stoneBreak;
    [SerializeField] private AudioClip portalEnter;
    [SerializeField] private AudioClip uiConfirm;
    [SerializeField] private AudioClip levelComplete;
    [SerializeField] private AudioClip uiError;
    [SerializeField] private AudioClip damage;

    private void Awake()
    {
        if (source == null)
        {
            source = GetComponent<AudioSource>();
        }

        if (source == null)
        {
            source = gameObject.AddComponent<AudioSource>();
        }

        source.playOnAwake = false;
        source.spatialBlend = 0f;
    }

    public void PlayPickup() => Play(pickup);
    public void PlayChestOpen() => Play(chestOpen);
    public void PlayStoneBreak() => Play(stoneBreak);
    public void PlayPortal() => Play(portalEnter);
    public void PlayUiConfirm() => Play(uiConfirm);
    public void PlayLevelComplete() => Play(levelComplete);
    public void PlayUiError() => Play(uiError);
    public void PlayDamage() => Play(damage);

    private void Play(AudioClip clip)
    {
        if (clip == null || source == null)
        {
            return;
        }

        source.PlayOneShot(clip);
    }
}

spatialBlend = 0 表示 2D 音效，左右声道不随相机距离变化；HUD、拾取和 UI 反馈通常用 2D。以后做场景内的 3D 声源再单独配置。

04

在事件成功时播放声音

按下面位置插入调用。注意都是在“成功”分支里，不是在 Update 开头。

PlayerGridMover.cs · 音效调用点
// 破石成功
if (maze.TryBreakStone(targetCell))
{
    audio.PlayStoneBreak();
}

// 开箱成功
if (maze.TryOpenChest(currentCell))
{
    stats.AddCoins(ChestCoins);
    stats.AddBombs(ChestBombs);
    audio.PlayChestOpen();
}

// 材料拾取成功
if (maze.TryCollectMaterial(currentCell))
{
    stats.AddMaterial();
    audio.PlayPickup();
}

// 传送成功
maze.MarkPortalPairKnown(maze.GetPortalId(currentCell));
audio.PlayPortal();

// 岩浆造成非致命伤害
stats.ApplyTile(tile);
if (tile == TileType.Lava && stats.IsAlive)
{
    audio.PlayDamage();
}

// 无配对传送门
audio.PlayUiError();

05

让 LevelFlowController 也使用音频

加入 Audio 引用，并在没有材料/完成/死亡时播放：

LevelFlowController.cs
[SerializeField] private AudioManager audio;

// Start 校验
if (playerStats == null || audio == null)
{
    Debug.LogError(
        "LevelFlowController: 请指定 PlayerStats 和 Audio。",
        this);
    enabled = false;
    return;
}

// 有材料到出口
SetState(LevelState.Completed);
audio.PlayLevelComplete();

// 没材料到出口
audio.PlayUiError();
HintShown?.Invoke("还需要找到材料。");

// 死亡
SetState(LevelState.Failed);
audio.PlayDamage();

把 GameManager 也拖到 LevelFlowController 的 Audio 字段。完整参考：solutions/0011/LevelFlowController.cs。

检索练习

先不要往上翻。

1. 为什么短音效适合 PlayOneShot？

PlayOneShot 允许拾取、爆炸等短音效叠加，不打断其他声音。

2. 音效应该在哪里播放？

每帧播放会叠加成噪音；事件成功一次，反馈一次。

3. UI/拾取音效通常如何设置空间混合？

UI/拾取反馈不应随相机距离衰减，使用 2D 音效更稳定。

4. 没有材料进入出口应该播放什么？

目标未满足是无效操作，用 error 反馈；有材料才播放过关音。

报错急救

现象处理
完全没有声音AudioSource 的 Volume、Mute、AudioListener；Game 视图是否静音。
只有部分事件没声音对应 Clip 字段是否为空；事件是否真的成功。
只有过关没声音AudioManager 的 Level Complete 字段是 None；拖入 level_complete.ogg。
音效叠成爆音检查是否在 Update 里调用；应该只在成功分支调用一次。
音乐被拾取声打断不要让短音效和音乐共用同一个 AudioSource。
Audio 引用为空把 GameManager 拖到 PlayerGridMover/LevelFlowController 的 Audio 字段。
