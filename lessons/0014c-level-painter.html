基础关卡画笔

你要做一个最小但真正可用的 EditorWindow：读取关卡、选择字符、点击格子、验证并应用。

60–90 分钟EditorWindow · Grid · Buffer产出：可绘制关卡

本课胜利条件

窗口只做三件事

SELECT

选择关卡

用 ObjectField 绑定一个 LevelDefinition。

EDIT

编辑缓冲

网格操作先改内存，不立即写资产。

COMMIT

应用结果

用户点 Apply 后才写 SerializedObject。

先定状态

窗口至少需要 LevelDefinition level、char[,] cells、char brush、bool isDirty。

01

建立最小窗口

public class LevelPainterWindow : EditorWindow
{
    [MenuItem("Color Maze/Levels/Level Painter")]
    private static void Open()
    {
        GetWindow<LevelPainterWindow>(
            "Level Painter");
    }
}

顶部放 EditorGUILayout.ObjectField。选择资产时，把它的 rows 复制成 char[,]；不要长期保存对 SerializedProperty 的引用。

02

制作调色板

调色板顺序固定为：

.  #  S  R  B  C  M  E  1 … 9

每个按钮用当前画笔高亮。传送门 1–9 可以放在第二行，避免窗口太宽。切换画笔不能修改地图。

03

画网格

用双层循环创建 GUILayout.Button。每个按钮宽高约 28–32px，按钮文字用 #、.、R 等字符。

  • 左键：把当前格设为画笔。
  • 右键：把当前格字符设为画笔，即“取样”。
  • 修改后设置 isDirty = true 并 Repaint()。
  • 始终在 (1,1) 显示红色起点标记，但不要改变地图字符。

地图行数组是“上到下”，坐标 y 是“下到上”。绘制时最容易在这里弄反。

04

应用、撤销与恢复

Apply 时把 char[,] 转回 string[]，然后用 SerializedObject 写入 rows。写入前注册 Undo，并调用 AssetDatabase.SaveAssets()。

Revert 重新从资产读取；有未应用修改时，切换关卡或关闭窗口要弹出 Save / Discard / Cancel。

不要靠 Inspector 自动 Undo

你修改的是窗口缓冲，必须显式注册 Undo。否则 Apply 后 Ctrl+Z 找不回上一张地图。

05

校验当前缓冲

把 14b 的 Codec 与 14 的 Validator 复用起来。Validate 检查的是窗口中的 char[,]，不是磁盘上的旧资产。

建议校验函数接收 string[] rows 与 stepLimit，LevelDefinition 版本只是读取字段后调用同一个函数。

06

验收

  1. 打开 Level_Water World，画三格再撤销。
  2. 右键吸取一个水格，再用它绘制另一格。
  3. 绘制、Validate、Apply，关闭窗口重新打开后内容一致。
  4. 不 Apply 就切换关卡，出现未保存提示。
