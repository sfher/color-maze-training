颜色开始有代价

现在踩上红蓝格只是换颜色。今天让岩浆扣生命、水耗氧气，并用一个临时 HUD 看见资源变化。

50–70 分钟 枚举 · 状态 · HUD 产出：可消耗的生命与氧气

本课胜利条件

先看规则表

格子符号走上这一格后
地板.氧气 +1（不超过 3）
墙#不能进入
岩浆R生命 -1；不在水中，氧气 +1（上限 3）
水B氧气 -1；氧气为 0 时改为生命 -1

这些规则来自你的项目预设：生命与氧气共同限制探索路线，让“最短路径”不一定是“最安全路径”。今天先把两条最核心的规则跑通。

一个容易忽略的预设细节

预设写的是“不在水中时，每走过一格自动恢复氧气”，所以岩浆格也会恢复 1 点氧气。这不是代码 bug，而是当前规则的字面结果；如果你觉得不合理，把它记成待平衡项，下一轮再改，不要悄悄改掉。

测试前先看当前关卡

你的场景当前绑定的是 Level_02，里面只有岩浆，没有水。测试水规则时，把 Maze 的 Level 字段切到 Level_01，或者给 Level_02 的某一行加一个 B。

本课的分工

Meaning

TileType

把字符翻译成有名字的格子类型：Floor、Wall、Lava、Water。规则代码不再直接比较 'R' 或 'B'。

State

PlayerStats

保存当前生命和氧气，并决定踩到某种格子后状态怎么变。它是唯一的“数值真相”。

orchestration

PlayerGridMover

先确认目标格可走，再移动，最后把“踩到了什么”交给 PlayerStats 处理。

01

创建 TileType.cs

在 Assets/Scripts 右键，选择 Create → C# Script，命名为 TileType。替换为：

TileType.cs
public enum TileType
{
    Floor,
    Wall,
    Lava,
    Water
}

enum 是一组有名字的固定选项。它比直接传字符更安全：编译器能检查拼写，Inspector 和调试器里也能读懂 Lava，而不是只看到一个 'R'。

02

让 LevelDefinition 返回格子类型

打开 LevelDefinition.cs，在 GetTile 后面加入：

LevelDefinition.cs · 新增方法
public TileType GetTileType(Vector2Int cell)
{
    switch (GetTile(cell))
    {
        case '.': return TileType.Floor;
        case '#': return TileType.Wall;
        case 'R': return TileType.Lava;
        case 'B': return TileType.Water;
        default: return TileType.Wall;
    }
}

未知字符默认按墙处理，避免地图写错时玩家能穿过一个“洋红色未知格”。这也是“失败要安全”的一个小例子。

03

让 MazeBootstrapper 暴露格子类型

打开 MazeBootstrapper.cs，按下面几处修改。核心是：IsWalkable 只判断是不是墙，其他格子类型交给 PlayerStats 决定后果。

MazeBootstrapper.cs · 改动清单
// Start 循环里：按类型生成，而不是按字符生成
TileType tile = level.GetTileType(new Vector2Int(x, y));
CreateCell(square, x, y, tile);

// 两个方法的参数从 char 改成 TileType
private void CreateCell(Sprite square, int x, int y, TileType tile)
private Color ColorFor(TileType tile)

// IsWalkable 只拦墙
public bool IsWalkable(Vector2Int cell)
{
    return GetTileType(cell) != TileType.Wall;
}

// 新增：给 PlayerGridMover 查询当前格子
public TileType GetTileType(Vector2Int cell)
{
    if (level == null || !level.Contains(cell))
    {
        return TileType.Wall;
    }

    return level.GetTileType(cell);
}

// ColorFor 的分支改用 TileType
private Color ColorFor(TileType tile)
{
    switch (tile)
    {
        case TileType.Wall: return new Color(0.10f, 0.10f, 0.12f);
        case TileType.Floor: return new Color(0.93f, 0.92f, 0.88f);
        case TileType.Lava: return new Color(0.82f, 0.22f, 0.20f);
        case TileType.Water: return new Color(0.16f, 0.45f, 0.86f);
        default: return Color.magenta;
    }
}

如果不想逐段改，可以直接用参考实现整份替换：solutions/0004/MazeBootstrapper.cs。这样也会修掉你当前文件里那处乱码的中文报错。

04

创建 PlayerStats.cs

在 Assets/Scripts 新建 C# 脚本 PlayerStats，替换为：

PlayerStats.cs
using UnityEngine;

public class PlayerStats : MonoBehaviour
{
    public const int MaxHealth = 3;
    public const int MaxOxygen = 3;

    public int Health { get; private set; } = MaxHealth;
    public int Oxygen { get; private set; } = MaxOxygen;

    public bool IsAlive => Health > 0;

    private GUIStyle _labelStyle;

    public void ApplyTile(TileType tile)
    {
        switch (tile)
        {
            case TileType.Lava:
                LoseHealth(1);
                RecoverOxygen();
                break;
            case TileType.Water:
                ConsumeOxygen();
                break;
            default:
                RecoverOxygen();
                break;
        }
    }

    private void LoseHealth(int amount)
    {
        Health = Mathf.Max(0, Health - amount);
        Debug.Log($"生命 -{amount}，剩余 {Health}");
    }

    private void ConsumeOxygen()
    {
        if (Oxygen > 0)
        {
            Oxygen -= 1;
            Debug.Log($"氧气 -1，剩余 {Oxygen}");
            return;
        }

        LoseHealth(1);
    }

    private void RecoverOxygen()
    {
        Oxygen = Mathf.Min(MaxOxygen, Oxygen + 1);
    }

    private void OnGUI()
    {
        if (_labelStyle == null)
        {
            _labelStyle = new GUIStyle(GUI.skin.label);
            _labelStyle.fontSize = 22;
            _labelStyle.normal.textColor = Color.black;
        }

        GUI.Box(new Rect(12f, 12f, 260f, 96f), "");
        GUI.Label(
            new Rect(24f, 22f, 236f, 30f),
            $"生命: {Health} / {MaxHealth}",
            _labelStyle);
        GUI.Label(
            new Rect(24f, 58f, 236f, 30f),
            $"氧气: {Oxygen} / {MaxOxygen}",
            _labelStyle);
    }
}

Health { get; private set; } 表示其他脚本可以读取生命值，但不能随便写入；只有 PlayerStats 自己能改。这就是“状态归所有者管理”。

这是临时调试 HUD

OnGUI 是 Unity 的即时模式 GUI，适合原型阶段快速看数值，不适合作为最终界面。正式 HUD 会在后面的 UI 课用 Canvas/TextMeshPro 重做；现在先把规则验证清楚。

05

让移动脚本调用规则

打开 PlayerGridMover.cs，做四处小改动：

PlayerGridMover.cs · 改动清单
// 1. 字段
private PlayerStats stats;

// 2. Start 里，maze 检查之后
stats = GetComponent<PlayerStats>();

if (stats == null)
{
    Debug.LogError(
        "PlayerGridMover: Player 上缺少 PlayerStats 组件。",
        this);
    enabled = false;
    return;
}

// 3. Update 开头
if (!stats.IsAlive)
{
    return;
}

// 4. TryMove 末尾，位置更新之后
stats.ApplyTile(maze.GetTileType(currentCell));

然后在 Unity 里选中 Player，点 Add Component，搜索并添加 PlayerStats。它必须和 PlayerGridMover 在同一个 GameObject 上，因为脚本用 GetComponent 查找它。

执行顺序很重要：先验证目标格 → 再移动 → 最后应用格子效果。如果先扣血再判断墙，玩家会为一次没走成的移动付出代价。

06

按四条路径验证状态

把 Maze 的 Level 字段切到 Level_01，点击 Game 视图，按下面顺序测试：

要验证的规则从起点 (1,1) 的走法预期
岩浆扣血W, W, W, D（到 (2,4)）生命 3 → 2；氧气已满，仍为 3
继续踩岩浆D（到 (3,4)）生命 2 → 1；氧气仍为 3
水耗氧重新 Play，D, D, W（到 (3,2)）氧气 3 → 2
离开水恢复继续 D, D（经过 (4,2)，到 (5,2) 地板）氧气先 2 → 1，再恢复到 2

要验证“氧气为 0 时踩水扣血”，Level_01 的两格水不够。停止 Play，把 Level_01 的水行临时改成 #.BBBB#，保存后再 Play：从起点按 W，然后连续按四次 D，第四次进入水格时生命会 -1。测完把这一行改回 #..BB.#。

HUD 应该显示什么

左上角显示 生命: 3 / 3 与 氧气: 3 / 3。如果数值不变，先看 Console 有没有 PlayerStats 缺失或引用错误。

检索练习：合上资料再答

先不要往上翻。答错没关系，努力回忆本身就在加固记忆。

1. 踩到红色 R 时应该发生什么？

岩浆消耗 1 点生命；水才消耗氧气。

2. 氧气为 0 时踩水，按设计应该怎样？

氧气耗尽后，水开始扣生命；这就是双资源压力。

3. 离开水走到地板时，氧气如何变化？

不在水中时每走一格恢复 1 点氧气，直到最大值 3。

4. 为什么规则不放在 SpriteRenderer 的颜色里？

颜色是表现，TileType 才是规则数据；换美术不应改变玩法。

报错急救

现象最可能原因处理
看不到 HUDPlayer 上没有 PlayerStats选中 Player，Add Component 添加 PlayerStats。
踩岩浆不扣血R 没有映射成 Lava，或 ApplyTile 没调用检查 GetTileType 的 R 分支与 TryMove 末尾。
踩水不耗氧当前关卡没有 B切到 Level_01，或给 Level_02 加一格 B。
氧气到 0 没扣血没有连续踩到足够多的水格把水行临时改成 #.BBBB# 再测。
生命为 0 还能走Update 没有检查 IsAlive在 Update 开头加 if (!stats.IsAlive) return;。
Console 中文乱码脚本编码不是 UTF-8用 UTF-8 保存；替换为课程参考实现即可恢复。
TileType 找不到脚本没编译或文件名不一致确认 TileType.cs 在 Assets/Scripts 下，类名一致。
