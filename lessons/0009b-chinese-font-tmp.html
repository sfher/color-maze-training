让中文 HUD
真正显示

默认 TMP 字体没有中文字形，所以中文变成方框。今天找一款许可明确的像素中文字体，生成 TMP Font Asset，并把它接入现有 HUD。

45–60 分钟 字体 · OFL · TMP Font Asset 产出：可显示中文的 HUD

本课胜利条件

为什么会出现方框

TextMeshPro 并不是直接使用 Windows 系统字体。它使用一个 Font Asset，里面包含字形、图集和渲染参数。TMP Essentials 默认字体主要是拉丁字符，中文字形不在里面，所以显示成方框或空白。

不是 UI 布局的问题

面板大小、Anchor 和 Canvas Scaler 都可能正确；问题只是当前字体资产没有“生”“命”“氧”这些字形。

解决路径是：找一款允许嵌入、覆盖简体中文的字体 → 导入 TTF/OTF → 生成 TMP Font Asset → 分配给文本或设为 fallback。

字体选择

字体特点许可/注意
Fusion Pixel Font泛中日韩像素字体，支持简体中文，提供 8/10/12px 等尺寸字体 OFL 1.1；仓库代码 MIT；适合本课
Noto Sans SC非像素、中文覆盖稳定OFL；适合作为备用方案
Zpix中文像素字体个人/教育免费，商业产品需付费；不要默认当免费商用

本课使用 Fusion Pixel Font。如果 Windows 的解压窗口要求密码，直接留空并继续即可；不需要去第三方网站找密码。

推荐先用较小的 10px 包：

官方大小：28,578,692 bytes

01

导入字体与许可

  1. 在 Unity 的 Project 窗口创建 Assets/ThirdParty/Fonts/FusionPixel/。
  2. 把选中的 TTF 拖进去。
  3. 把原始 OFL.txt 和整个 LICENSES/ 目录原样放进去，不要删改。
  4. 在项目根目录创建或更新 THIRD_PARTY_NOTICES.md，记录字体名称、作者、版本、来源、许可、修改和日期。
THIRD_PARTY_NOTICES.md · 字体记录
| Font-01 | Fusion Pixel Font | TakWolf | GitHub release 2026.10.16 | OFL 1.1 (font), MIT (repo code) | 2026-10-21 | Converted to TMP Font Asset (dynamic) | Preserve OFL.txt and LICENSES/ |
02

生成 TMP Font Asset

  1. 选中 TTF，在 Inspector 确认它是 Font 资源，并且能正常导入。
  2. 打开 Window → TextMeshPro → Font Asset Creator。
  3. Source Font File 选择刚导入的 TTF。
  4. Atlas Resolution 先用 1024 × 1024；Padding 设为 5。
  5. Atlas Population Mode 选 Dynamic。如果当前 TMP 版本的 Creator 没有这个选项，生成后在字体资产 Inspector 里把 Atlas Population Mode 改成 Dynamic。
  6. Character Set 可以先选 Custom Characters，填入 HUD 当前用到的中文、数字和标点；以后要扩展文本，Dynamic 会按需生成缺失字形。
  7. 点击 Generate Font Atlas，保存为 FusionPixel SDF.asset，放在同一个字体目录。
Dynamic 与 Static 的取舍

Dynamic 会按需把新字加入图集，适合持续增加中文文本；Static 只包含你指定的字符，图集更小但以后出现新字会缺字。原型阶段先用 Dynamic，项目稳定后再做字符集裁剪。

03

把字体接到 HUD

有两种接法，推荐先做全局 fallback：

方式 A：TMP 全局 fallback

  1. 打开 Project Settings → TextMesh Pro → Settings。
  2. 在 Fallback Font Assets 列表中加入 FusionPixel SDF。
  3. 当前 HUD 文本仍然使用默认字体的拉丁字形；遇到中文时自动 fallback 到中文字体。

方式 B：直接分配给每个 Text

选中 StatsText、EndTitleText、EndHintText、HintText 和按钮文字，把 Font Asset 直接设为 FusionPixel SDF。这种方式更直观，但每个文本都要绑定，容易漏。

把 HUD 字号设置为像素字体的整数倍：10px 字体建议使用 20、30、40；12px 字体建议使用 24、36、48。原来的 28/44 会经过插值，可能不够锐利。

04

验证字形和布局

  1. Play，HUD 应显示“生命”“氧气”“炸弹”“金币”“材料”，不再出现方框。
  2. 检查数字、中文标点和空格；缺字时查看字体资产的 Glyph Table。
  3. 把 Game 视图切换到不同分辨率，确认文字没有裁切。
  4. 确认字体许可证、字体资产、Atlas/Material 和 .meta 都在项目中。
如果仍然有方框

先确认文本的 Font Asset 是否真的指向中文字体资产；再确认该字体的 Atlas Population Mode 是 Dynamic，且 Glyph Table 中有对应汉字。Canvas 布局正常但字形缺失，问题仍然在字体资产，不在 RectTransform。

检索练习

先不要往上翻。

1. TMP 中文显示方框，最可能是什么？

默认字体资产没有中文 Glyph；布局与字形覆盖是两件事。

2. Fusion Pixel Font 的字体文件使用什么许可？

字体使用 OFL 1.1；保留版权/许可文本，并记录修改与来源。

3. Dynamic Font Asset 的主要特点是什么？

Dynamic 会把运行时出现的字形加入图集，适合持续增加的中文文本。

4. 字体来源与许可应该记录在哪里？

把作者、版本、链接、许可和修改写进 THIRD_PARTY_NOTICES.md，并保留许可原文。

故障复盘：状态栏正常，结算却方框

这是本项目真实踩过的坑，留给一个月后的你：

症状

状态栏“生命/氧气/炸弹/金币/材料”正常，进入结算界面后“关卡完成 / 找到了材料了”出现方框。Console 警告类似：

The character with Unicode value \u627E was not found in [FusionPixel12SDF]...
The character with Unicode value \u5173 was not found in [FusionPixel12SDF]...

这次实际上是两层问题叠加：

  1. Material 不匹配：结算文本的 Font Asset 指向 Fusion 字体，但 Material 仍是默认 LiberationSans 的材质。只换 Font Asset、不换材质，字形仍然查错图集。
  2. Atlas 已满：1024×1024 图集已经用到约 1013×1013，并且 Multi Atlas Textures 关闭。Dynamic 没有空间生成新字形，于是报警并显示方框。

修复顺序：

  1. 把同一个 TMP Font Asset 的 Font Asset + Material 一起应用到所有 HUD 文本。
  2. 在字体资产上开启 Multi Atlas Textures。
  3. 确认 Atlas Population Mode 是 Dynamic，Source Font File 存在。
  4. 让字体资产重新导入/保存后，停止 Play 再重新 Play；正在运行的 Play 会话可能还持有旧图集。
  5. 必要时用 TryAddCharacters 或 Font Asset Creator 预先把 HUD 实际用到的字符加入图集。
一个月后的检查清单

看到“部分文本正常、部分文本方框”，先查 Material；看到“字体文件明明有字但 Dynamic 不补”，查 Atlas 容量和 Multi Atlas。Dynamic 不是无限容量，也不是自动修复所有引用。

报错急救

现象处理
仍有方框确认 Font Asset 是 FusionPixel，且 Material 也是该字体的材质。
只有部分字缺失检查 Atlas 是否已满、Multi Atlas 是否开启；再查源 TTF 和 Glyph Table。
状态栏正常、结算方框结算 Text 的 Font Asset 或 Material 没有统一。
Atlas 用到接近 1024图集已满；开启 Multi Atlas，或降低 sampling point size 重新生成。
字体很糊使用所选字体尺寸的整数倍（10px: 20/30/40；12px: 24/36/48），检查 Canvas 缩放。
字体资产没生成确认 TTF 已导入、Creator 的 Source Font 正确、图集分辨率足够。
Inspector 找不到 fallback先在 Text 的 Font Asset 直接指定中文字体，再处理全局设置。
许可页打不开从 release 原始包中保留 OFL.txt 和 LICENSES/；不要删除许可文件。
