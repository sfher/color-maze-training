宝箱不是装饰
是资源入口

上一课炸弹只能靠初始数量。今天加金色宝箱：走上去打开，获得金币和炸弹，宝箱变成地板，奖励只发一次。

45–60 分钟 交互 · 资源 · 运行时替换 产出：宝箱与金币循环

本课胜利条件

本课的交互选择

宝箱可以做成“按 F 打开”，也可以做成“走上去自动打开”。原型阶段先用后者：少一个输入键，能更快验证资源循环。以后要加开箱动画、音效或确认框，再把交互拆成独立步骤也不迟。

Step

进入宝箱格

玩家移动成功后检查当前格。宝箱可通行，但进入后触发一次开箱。

Replace

变成地板

开箱后把运行时格子改成 Floor，并更新渲染器颜色，保证不会重复奖励。

Reward

资源入账

金币和炸弹都归 PlayerStats 管理，HUD 只负责显示。

原型阶段先固定掉落

本课所有宝箱都固定给 +3 金币、+1 炸弹。等之后做道具表或掉落配置，再把固定值换成数据驱动。先验证“打开一次、入账一次、资源可用”。

02

把“替换格子”抽成一个方法

上一课的 TryBreakStone 已经会“检查目标 → 改运行时格子 → 更新颜色”。宝箱也是同一件事，所以抽成公共方法，避免复制：

MazeBootstrapper.cs · 替换逻辑
public bool TryBreakStone(Vector2Int cell)
{
    return TryReplace(cell, TileType.Stone, TileType.Floor);
}

public bool TryOpenChest(Vector2Int cell)
{
    return TryReplace(cell, TileType.Chest, TileType.Floor);
}

private bool TryReplace(
    Vector2Int cell,
    TileType expected,
    TileType replacement)
{
    if (GetTileType(cell) != expected)
    {
        return false;
    }

    _tiles[cell.x, cell.y] = replacement;
    _renderers[cell.x, cell.y].color = ColorFor(replacement);
    return true;
}

宝箱开完变成 Floor，所以第二次进入时 GetTileType 不再是 Chest，奖励不会重复发放。运行时副本仍然不改动 LevelDefinition 资产。

04

走上宝箱时开箱

在 PlayerGridMover.cs 里加两个常量，并修改移动成功后的处理：

PlayerGridMover.cs
private const int ChestCoins = 3;
private const int ChestBombs = 1;

// TryMove 末尾，更新位置之后
if (maze.GetTileType(currentCell) == TileType.Chest)
{
    if (maze.TryOpenChest(currentCell))
    {
        stats.AddCoins(ChestCoins);
        stats.AddBombs(ChestBombs);
        Debug.Log("宝箱: 金币 +3，炸弹 +1");
    }

    stats.ApplyTile(TileType.Floor);
    return;
}

stats.ApplyTile(maze.GetTileType(currentCell));

宝箱不是危险格，开箱后按地板处理，所以氧气会正常恢复。只有 TryOpenChest 返回 true 才发奖励；这是“先确认交互成功，再提交资源”的同一原则。

05

测试资源循环

  1. Play，HUD 应显示 金币: 0、炸弹: 1。
  2. D 撞石头，E 炸开：炸弹 1 → 0。
  3. D 进入石头格，再 D 进入宝箱：金币 0 → 3，炸弹 0 → 1。
  4. 离开宝箱格再回来：金币和炸弹不再增加。
  5. 停止 Play，确认 Level_01 里的 C 还在；再次 Play，宝箱和金币都回到初始状态。
本课验证的是“循环”

炸弹开路 → 宝箱补充炸弹 → 可以继续开路。金币先只显示，商店消费会在元循环阶段加入。

检索练习：合上资料再答

先不要往上翻。答错没关系，努力回忆本身就在加固记忆。

1. 本课宝箱如何触发？

原型阶段用“走上格子自动开箱”，减少一个交互键；以后可以改成独立交互。

2. 怎样保证宝箱只奖励一次？

运行时格子从 Chest 变成 Floor，第二次进入就不会再满足开箱条件。

3. 金币数量应该由谁保存？

金币是玩家这一局的状态，归 PlayerStats；关卡资产只保存模板数据。

4. 开箱后为什么调用 ApplyTile(Floor)？

宝箱开完就是地板，按地板规则恢复氧气；同时避免把宝箱当成危险格。
