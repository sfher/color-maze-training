像素素材

玩法已经用纯色方块验证完了。今天开始换皮：先把一批许可证干净的像素地块导入工程、切好、登记，不写一行代码。

45–60 分钟Sourcing · Import · Notices产出：可用地块素材库

本课胜利条件

本课在管线里的位置

这节课不碰 MazeBootstrapper——它现在给每个格子挂 SpriteRenderer，用运行时生成的白色方块上色（CreateSquareSprite）。15b 才把这些白色方块换成今天的素材。所以本课全部动作都在导入侧：

素材管线
需求清单 → 搜索(三轮关键词) → 许可证判定 → 下载进 ThirdParty
    → 导入设置(PPU/Point/None) → Sprite Editor 切图
    → THIRD_PARTY_NOTICES 登记 → 临时场景冒烟 → 提交

顺序不能倒：先定"要什么"，再看"哪里有"；许可证不明的不下载，下载了的必须登记。

01

先写需求清单

对着 TileType 数一遍，别多别少：

图对应数量
地板 / 墙 / 灰石 / 岩浆 / 水. # S R B各 1 起步
宝箱 / 材料 / 出口C M E各 1 起步
传送门1–91 张底图（15b 用颜色区分编号）
玩家Player 方块1

两个一旦定下就全项目统一的决定：

  • 分辨率：16×16 或 32×32。当前迷宫 1 格 = 1 世界单位，所以 PPU = 贴图边长，一个 sprite 正好一格。
  • 风格：优先同一个包吃下全部地块。混包必须同分辨率、同色板，否则 15b 换上去会像两款游戏。
提示

12a 的商店内容目录还在等主题图和关卡预览。今天选包时就留意：这个包的背景/装饰图之后能不能顺手供给商店，一次搜索喂两条管线。

02

搜索与许可证判定

首选 Kenney：项目已经用它的 CC0 音频，像素包多、风格统一、许可干净。检索方法沿用 09c 的三轮关键词法：直译 → 同义（pixel tileset / dungeon tiles）→ 场景描述（top-down 16x16 tileset CC0）。

许可证结论要做什么
CC0 1.0✅ 最省心notices 记录来源即可
CC-BY 4.0⚠️ 可用notices 记署名；发布物里保留 credit
OFL✅ 字体专用保留 LICENSE-OFL（照 09b 先例）
没写 / "free to use"❌ 不用换素材，不猜许可

itch.io 的包以随包 license 文件或作者页明示为准，页面没写就是没有。OpenGameArt 逐素材核对，不按站点整体判断。

03

放进工程并设置导入

目录沿用现有约定（参照 Audio 的先例）：

目录结构
Assets/ThirdParty/Art/
  Kenney/
    <pack-name>/
      tileset_*.png
      License.txt          ← 原包许可必须一起进仓库

选中纹理，在 Inspector 按这张表设置（逐项对照 Unity 官方 Import Settings 文档）：

设置值为什么
Texture TypeSprite (2D and UI)作为 Sprite 使用并启用 Sprite Editor
Sprite ModeMultiple（雪图）/ Single（单图）一张图多地块必须切分
Pixels Per Unit16（或 32）= 贴图边长1 sprite = 1 世界单位 = 迷宫 1 格
Filter ModePoint (no filter)像素画放大不清边缘
CompressionNone有损压缩会让像素色块渗色
Max Size≥ 原图边长别让 Unity 缩图

然后 Sprite Editor → Slice → Grid By Cell Size，填贴图边长（16×16 或 32×32）→ Slice → Apply。Project 里展开纹理，每个地块变成一个子 Sprite。

常见错误

PPU 留默认 100：16×16 的 sprite 只占 0.16 格，小到看不见。Filter 留 Bilinear：像素边缘发糊。混用 16 和 32 两个包：格子大小不一。三种都是本课冒烟步骤能当场抓住的错。

04

登记授权清单

在 Color Maze/THIRD_PARTY_NOTICES.md 照现有格式加一行，并更新 Local Files 与 License Texts：

inventory 新行示例
| kenney-pixel-tiles | Pixel Pack 名称 | Kenney | [下载页 URL] | CC0 1.0 | 2026-10-24 | 选用地块切片，未修改原图 | Not required; credit appreciated |

日期必须有——notices 自己的 Notes 写着"a link without a date becomes hard to audit later"。

05

冒烟验证（不弄脏 Main 场景）

  1. File → New Scene（之后不保存）。
  2. 从 Project 拖一个地板 Sprite 到 Scene 视图。
  3. 检查三点：Transform 的 scale 为 1 时 sprite 约占 1×1 世界单位；放大后像素边缘锐利；没有半透明的渗色边。
  4. 故意把 Filter 改成 Bilinear 看一次模糊的样子，再改回 Point——以后一眼就能认出这个病。
  5. 关闭场景，不保存。

主场景 Main.unity 一个字节都不要动，15b 才动它。

验收与提交

  • 胜利条件全部勾选。
  • 提交内容：Assets/ThirdParty/Art/ 全部 png + .meta + 许可文件 + THIRD_PARTY_NOTICES.md。png 不带 .meta 提交，下次打开工程引用全断。
  • 提交信息建议：assets(art): import pixel tile pack with licenses。
  • 开发日志 3 行：选了哪个包、为什么（许可证/风格/数量）、PPU 定了多少。

做完把"选了哪个包、notices 新行截图"发我，我帮你复核许可记录。卡住时先说卡在哪一步：找不到合适的包、许可证拿不准、还是切图切歪了。下一课 15b 才把这些 sprite 接进 MazeBootstrapper。
