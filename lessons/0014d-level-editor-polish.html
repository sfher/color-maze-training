把编辑器
变成工作流

基础画笔完成后，补上新建关卡、尺寸调整、未保存保护和校验面板。目标是让策划不碰 YAML，也能独立完成一张关卡。

60–90 分钟AssetDatabase · Undo · Workflow产出：完整制作闭环

本课胜利条件

01

新建关卡资产

顶部增加 New Level：选择保存路径与文件名，默认创建 9×9：

#########
#.......#
#.......#
#.......#
#...M...#
#.......#
#.......#
#......E#
#########

默认 StepLimit = 30，侧关卡 Next Level = None。创建后立即交给窗口编辑，不要求先手填一张占位图。

示例使用一圈墙作为视觉脚手架，但这不是硬性格式。地图的行列范围本身已经形成边界；省略外圈 `#` 仍是合法关卡。

02

调整尺寸

显示 Width / Height，并允许 Resize。规则固定：

  • 保留左上区域，也就是现有 rows 和列号尽量不变。
  • 新增格使用当前画笔填充；默认画笔建议为墙 #，便于画局部隔墙或房间边界。
  • 缩小造成地图丢失前弹出确认。
  • Resize 先改窗口缓冲，点击 Apply 后才写资产。
03

补完编辑状态

关闭、切换关卡、重新载入时必须检查 isDirty：

Save / Discard / Cancel

Apply 后清除 dirty，并保存资产。Undo/Redo 尽量通过 Unity 原生历史完成；如果窗口自身无法覆盖所有判断，至少保证 Apply 的整张地图变更可以撤销。

04

用校验结果指导绘制

窗口下方显示错误列表，至少覆盖：

  • 行宽不一致与未知字符所在行列；
  • 起点 `(1,1)` 不可走；
  • 材料数少于所需数量，或出口不是恰好一个；
  • 传送门编号不是恰好两个；
  • 步数上限小于等于 0。

校验失败时仍可保存 draft，但状态必须明确显示“未通过”；不要用静默自动修正掩盖地图错误。

05

最终验收

  1. 不使用文本编辑器，新建一张关卡。
  2. 画出所需材料、出口和一个成对传送门；目标规则允许多余材料，但迁移前校验器仍要求材料恰好一个。
  3. 故意画错一行，确认错误能定位到行列。
  4. 修复、Apply、关闭窗口并重新打开，内容仍然存在。
  5. 在 Play 中加载该关卡，确认能正常移动并显示地图。

卡住时把“哪一步操作、预期、实际、Console”发我。先自己尝试，不要求一次就写对。
