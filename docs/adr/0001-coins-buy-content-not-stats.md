# ADR-0001: 金币只购买内容，不购买数值强化

日期：2026-10-24 · 状态：已接受

## 背景

《色彩迷宫》的核心玩法是单局策略：固定初始资源（生命 3 / 氧气 3 / 炸弹 0）、步数限制、路线取舍。课程 12 曾按"补给站"方向实现了生命/氧气/炸弹的数值强化购买（solutions/0016，未接入工程）。

## 决策

金币只能购买**装饰与内容**（皮肤、主题、附加关卡）；不出售任何影响关卡内规则数值的强化。

## 理由

数值强化会把游戏从"每局独立的策略题"变成"养成 + roguelike"：关卡设计将被迫假设玩家资源上限可变，难度曲线失去基准（设计指南的全部约束都以固定初始资源为前提）。装饰与内容不影响单局规则，两套目标互不干扰。

## 后果

- 课程 12 的数值商店实现保留在 solutions/0016 但不接入；`PurchaseResult` 的语义被 16a 的 `PurchaseOutcome`（Purchased / NotEnoughCoins / AlreadyOwned / InvalidEntry）继承。
- 存档经济模型只需 `coins` 与 `unlockedContentIds`（13 课已预留）。
- 若未来重开数值线，属于推翻本决策：关卡设计约束、平衡与存档都要重估。
