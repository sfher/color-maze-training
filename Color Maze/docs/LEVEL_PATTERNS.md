# 关卡结构速查（进阶）

**难关不是路更多，而是每个房间只问一个问题，并让玩家为答案付出代价。**

符号：`@` 玩家、`b` 炸弹、`+` 爆炸范围、`?` 未知区域。

## 三条原则

1. 一个房间只引入一个新问题；下一房间再组合。
2. 短路线伤资源，长路线耗步数；两条路不能同时更快、更安全。
3. 关键危险必须提前看见。未知可以制造紧张，不能制造不可预测的死亡。

## 水与生命结构

### `.BB.BB.`：分段趟水，不掉血

```text
.BB.BB.
```

连续两格水后踩一格地板回氧，再过两格水。氧气会到 0，但生命不掉。

用途：让玩家发现“中间落脚点”；比连续水更温和。

### `BBBBB`：同样是水，多走即受伤

```text
BBBBB
```

前三格耗尽氧气，第四、五格各扣 1 生命。

用途：把看似相同的蓝色区域变成资源考试。

### `BBBBBB`：满血也无法硬穿

```text
BBBBBB
```

损失 3 生命，直接死亡。

用途：明确告诉玩家“这不是勇气的题，是绕路或改路的题”。

### `BBB.RBB`：危险后的喘息点

```text
BBB.RBB
```

第三格水后氧气为 0，`.` 恢复 1 点，岩浆再恢复 1 点但扣 1 生命。

用途：设计“受伤买氧气”的路线，但不要连续堆两次。

---

## 岩浆结构

### `R`：一次可承受的冒险

```text
R
```

扣 1 生命，之后有完整生命余量。

### `RR`：已经进入残血路线

```text
RR
```

扣 2 生命，只剩 1 生命。出口前还有任何危险都会让路线失效。

### `RRR`：满血也会死亡

```text
RRR
```

除非中间有明确恢复机制，否则不要放在必经路线。

## 炸弹结构

### 安全引信路

```text
#####
#b..#
#.#.#
#...#
#####
```

玩家放弹后必须离开十字范围：

```text
  +
+ b +
  +
```

用途：先教“放、撤、等三步”，再增加其他敌人或限步。

### 封闭石牢

```text
#####
#S@S#
#####
```

**这是软锁，不是难关。** 玩家放弹后没有有效移动，三步引信永远不走。

修正：至少留一条能绕出十字范围的三步通道。

### 炸弹只够开一条路

```text
#..S.....M#
#..#####S.#
```

若只有一个宝箱，就只能选择一条石墙。另一条必须绕路，不能也强制破石。

用途：制造“把唯一炸弹用在哪里”的决策。

### 爆炸自伤

```text
#####
#.S.#
#S@.#
#...#
#####
```

把石头和玩家都在十字内。玩家能开路，也可能被自己的爆炸扣 1 生命。

用途：让炸弹从“钥匙”变成“带代价的钥匙”。

## 步数结构

### 让同一条路产生三种结果

```text
安全路：9 步，0 伤害
危险路：6 步，损失 2 生命
```

设步数上限后：

| 步数上限 | 可达结果 |
|---:|---|
| 5 | 无法完成 |
| 7 | 只能走危险路，残血通过 |
| 10 | 两条路都能走，可以满血通过 |

这是本作最重要的难度结构。关卡是否“好玩”，取决于玩家能否看见并选择这两条路。

### 传送门消耗步数

```text
@.......1
##########
..........
1.......E
```

传送门缩短距离，但进入传送门本身仍算 1 步。不要把所有步数压力都藏在传送门后面。

### 假捷径

```text
@..RRR..
........
........E
```

上方更短但扣生命；下方更长但安全。步数上限必须卡在两者之间，而不是两者都无压力通过。

## 宝箱与炸弹

玩家初始炸弹为 0。

```text
@..C..S..M
```

可过：先拿宝箱，再破石。

```text
@..S.....C..M
```

不可过：无炸弹时先被石墙封死。

```text
@..C..S..C..S..M
```

资源链：一个宝箱对应一个必须破开的石墙。不要让两个宝箱看起来可拿，实际却只够打开一个。

## 组合关卡

一个进阶房间最多组合两个问题：

```text
资源：水或岩浆
时间：步数上限
空间：石头或传送门
```

推荐组合：

```text
水 + 步数：安全绕路很长
岩浆 + 炸弹：炸墙后仍有自伤风险
传送门 + 宝箱：传送门省步，但宝箱在危险支路
石头 + 步数：破墙路线更短，却可能少拿资源
```

避免组合：

```text
看不见的传送出口 + 必死岩浆
唯一炸弹 + 两个必须破开的石墙
连续六格水 + 没有休息点
封闭石牢 + 只能等待的三步引信
```

## 提交前只看五点

- [ ] 最短安全路线和最短危险路线不同。
- [ ] 步数上限能产生失败、残血、满血三种结果。
- [ ] 炸弹房间至少有路离开爆炸十字。
- [ ] 初始 0 炸弹时，需要破石前能先拿到宝箱。
- [ ] 玩家在受罚前能看到导致受罚的结构。
