本文是课程 16 系列的需求与验收基准。任何与本文冲突的后续改动，先改本文再动工。

## 1. 定位

金币购买**装饰与内容**（皮肤、主题、关卡），不购买关卡内数值强化——保持"单局策略"纯度，数值养成线（课程 12）继续搁置。理由见 ADR-0001。

## 3. 主菜单（独立场景 MainMenu）

按钮：开始游戏 / 读取存档 / 清空存档 / 选择关卡 / 商店 / 设置 / 退出游戏。

- **开始游戏**：无存档 → 直接 Level_01；有存档 → 确认框警告覆盖 → 清档 + Level_01 + **开场通讯**（MAYA 风格 3–4 句交代背景，草稿见附录）。
- **读取存档**：恢复 `lastLevelId` 进度与金币/装备；无存档置灰。
- **清空存档**：确认框 → 删档（按钮态刷新）。
- **选择关卡**：主线 Level_01→06 **顺序解锁**（首关默认开，通关 N 解锁 N+1）；购买关卡列尾部带"附加"标记，解锁即玩。
- **设置**：复用现有 SettingsPanel。
- **商店**：见 §4。
- **退出游戏**：保存当前设置与进度后关闭 Windows 玩家。

## 4. 商店规则

- 买断制；单选装备（皮肤、主题各一个装备位）；购买即解锁进 `unlockedContentIds`。
- 默认皮肤与默认主题始终视为已拥有；主题列表保留“经典（默认）”用于切回初始视觉。
- 无试穿；条目静态预览（sprite 即预览）。
- 购买结果枚举：`Purchased / NotEnoughCoins / AlreadyOwned / InvalidEntry`。
- 装备主题**下一局生效**（进关时读 `equippedThemeId` 换 `TileVisuals`）。

## 5. 金币经济

- 来源：宝箱 3/箱（不变）+ **首通奖励 +10**（`completedLevelIds` 判重）。
- **金币结算**：通关时把本局 `PlayerStats.Coins` 累计进存档；失败/重开不结算。
- 定价见 §2；2026-10-26 根据玩家反馈统一降至初版约一半，优先让玩家体验内容。

## 6. 存档（GameSaveData v2）

新增：`equippedSkinId`、`equippedThemeId`、`lastLevelId`、`completedLevelIds`。版本 1→2 一次性迁移（缺失字段取默认：默认皮肤、无主题、无通关记录）。

## 7. 分工

- **助手**：主菜单场景与场景流 + 开场通讯 + 商店/选关面板 UI（含展示层脚本）；三款主题资产；回廊与水世界重置的地图设计；目录维护；16a 课程与参考实现。
- **用户**：16a 元玩法实现（ContentCatalog / 购买与装备 / 存档扩展 / 金币结算 / 皮肤主题应用）；关卡资产落地。

## 8. 课程拆分

16a 元玩法核心（用户实现）→ 16b 主菜单与场景流（助手交付）→ 16c 商店与选关 UI 接线（助手 UI 层）。
