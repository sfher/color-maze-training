# 色彩迷宫 · Unity 开发实训

这是一个公开的长期教学工作区：用真实的 Unity 项目学习 C#、Unity
与独立游戏开发规范。游戏本身位于 [`Color Maze/`](Color%20Maze/)，
适合 Windows 平台。

> 这是一个学习与实践项目，不是商业团队产品。开发、课程规划与复盘使用了
> OpenAI Codex，并通过 Matt Pocock 的 `teach` skill 组织长期学习流程。
> 详细说明见 [CREDITS.md](CREDITS.md)。

## 从这里开始

1. 打开 [课程 01：把策划案变成第一屏彩色迷宫](lessons/0001-first-color-grid.html)。
2. 按课中的胜利条件逐步完成；每完成一步就勾选。
3. 卡住时把 Console 报错和当前代码贴回来，我们按你的实际进度继续。

## 工作区结构

- `MISSION.md`：为什么学、学成什么样；所有课程都围绕它。
- `CURRICULUM.md`：按开发阶段排的课程路线。
- `lessons/`：每课一个自包含 HTML，按编号推进。
- `reference/`：可打印的速查卡与术语表。
- `practice/`：闭卷练习与手搓任务。
- `solutions/`：卡住时对照的参考实现。
- `assets/`：课程共用的样式与交互组件。
- `tools/preview.mjs`：本地预览与交互自检工具。
- [`Color Maze/docs/LEVEL_DESIGN_GUIDE.md`](Color%20Maze/docs/LEVEL_DESIGN_GUIDE.md)：给外部关卡策划的关卡格式、规则、测试与提交指南。
- [`Color Maze/docs/LEVEL_PATTERNS.md`](Color%20Maze/docs/LEVEL_PATTERNS.md)：短版进阶关卡结构速查。
- `项目预设.md`：原始项目概念文档，是课程的内容来源。

## 每课固定动作

预测 → 实现 → 检索 → Git 提交 → 写三行开发日志。

课程不追求“看完”，追求“做出来、讲得清、下次还能接上”。
