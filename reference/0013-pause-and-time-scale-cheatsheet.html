暂停与 timeScale

暂停是一个可以回到 Playing 的状态。时间停住不等于 Update 停住，输入和 UI 仍需要明确管理。

打印友好 Paused Time.timeScale

状态转换

Playing --Esc--> Paused
Paused  --Esc--> Playing
Paused  --Restart--> scene reload
Playing --material+exit--> Completed
Playing --health 0--> Failed

Completed/Failed 不接受暂停；只允许 R 或按钮重开。

暂停/继续

SetState(Paused);
Time.timeScale = 0f;

SetState(Playing);
Time.timeScale = 1f;

先改状态再停时间，或先停时间再改状态都可以；关键是两者都发生，恢复时两者都回来。

Update 仍在执行

  • Time.timeScale = 0：物理/基于时间的动画停。
  • Update 仍执行，所以 Esc 仍能被检测。
  • 移动脚本必须检查 flow.IsPlaying。
  • 定时 UI 用 WaitForSecondsRealtime。

音频

audio.PlayUiConfirm();

// 短音效不依赖 timeScale
source.PlayOneShot(uiConfirm);

本课没有暂停 AudioListener，因此暂停/继续确认音仍可播放。背景音乐暂停需要单独设计。

UI 面板

pausePanel.SetActive(
    flow.State == LevelState.Paused);

endPanel.SetActive(
    State == Completed || State == Failed);

暂停面板和结算面板互斥；不要在暂停时同时显示结算。

按钮

  • ResumeButton → flow.Resume
  • PauseRestartButton → flow.Restart
  • OnDestroy 移除监听。
  • EventSystem 必须存在。

测试清单

  • Esc 显示/隐藏暂停面板。
  • 暂停时玩家不移动、不响应炸弹。
  • 继续后恢复输入。
  • 暂停时重开，timeScale 恢复为 1。
  • 结算时按 Esc 不进入暂停。
  • 暂停/继续只播放一次确认音。

报错急救

Esc 没反应
Game 视图焦点、Escape 输入、Flow 是否启用。
暂停还能走
PlayerGridMover 没有检查 flow.IsPlaying。
重开仍冻结
Restart/新场景 Start 没有恢复 timeScale=1。
面板按钮无效
GameHud 未绑定按钮，或场景缺 EventSystem。
结算还能暂停
Esc 状态判断范围写错。
