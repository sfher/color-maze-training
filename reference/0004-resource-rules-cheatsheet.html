生命与氧气规则

规则属于数据与状态，不属于颜色。颜色只是把格子类型画出来；真正的“踩上去会发生什么”由 TileType 和 PlayerStats 决定。

规则表

格子符号效果
地板.氧气 +1（上限 3）
墙#不可进入
岩浆R生命 -1；氧气 +1（上限 3）
水B氧气 -1；为 0 时生命 -1

TileType

public enum TileType
{
    Floor,
    Wall,
    Lava,
    Water
}

枚举把“裸字符”变成有名字的规则类型。扩展灰石、宝箱、传送门时，先加枚举值，再补映射。

字符 → 类型

public TileType GetTileType(Vector2Int cell)
{
    switch (GetTile(cell))
    {
        case '.': return TileType.Floor;
        case '#': return TileType.Wall;
        case 'R': return TileType.Lava;
        case 'B': return TileType.Water;
        default: return TileType.Wall;
    }
}

未知字符默认按墙处理：地图写错时玩家会被挡住，而不是穿进未知区域。

PlayerStats 状态

Health: 3 → 2 → 1 → 0
Oxygen: 3 → 2 → 1 → 0

Lava      → Health -1, Oxygen +1
Water     → Oxygen -1
Oxygen 0  → Water 改为 Health -1
Floor     → Oxygen +1（上限 3）

状态字段用 { get; private set; }：外部可读，只有 PlayerStats 自己能改。

应用顺序

1. target = current + direction
2. if (!maze.IsWalkable(target)) return
3. current = target
4. transform.position = maze.CellToWorld(current)
5. stats.ApplyTile(maze.GetTileType(current))

先验证再提交，最后才应用效果。这样撞墙不会扣血，也不会出现“没移动却消耗资源”。

临时 HUD

private void OnGUI()
{
    GUI.Box(new Rect(12, 12, 260, 96), "");
    GUI.Label(new Rect(24, 22, 236, 30),
        $"生命: {Health} / {MaxHealth}");
    GUI.Label(new Rect(24, 58, 236, 30),
        $"氧气: {Oxygen} / {MaxOxygen}");
}

OnGUI 适合原型和调试，不是最终 UI。正式 HUD 后面用 Canvas/TextMeshPro。

测试清单

  • 踩 R：生命 -1，氧气 +1（上限 3）。
  • 踩 B：氧气 -1，生命不变。
  • 连续踩水四次：氧气 0 后生命 -1。
  • 离开水到地板：氧气 +1。
  • 生命 0：玩家不能再移动。
  • 撞墙：不扣任何资源。

报错急救

HUD 不显示
Player 上没有 PlayerStats，或组件被禁用。
数值不变
TryMove 没有调用 ApplyTile，或 stats 为空。
水不耗氧
当前关卡没有 B；切到 Level_01 或给数据加 B。
氧气不尽
水格太少；临时把水行改成连续四格测试。
死后还能走
Update 没有检查 stats.IsAlive。
