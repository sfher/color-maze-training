关卡流与下一关

场景重载重建对象；关卡选择要跨载入保留。GameSession 只保存本次运行的当前关卡，不是正式存档。

打印友好 ScriptableObject Scene Flow

数据流

LevelDefinition.NextLevel
        ↓
GameSession.CurrentLevel
        ↓
SceneManager.LoadScene
        ↓
MazeBootstrapper.Awake
        ↓
build new grid

不要把下一关名字写死在代码里；把引用放到关卡资产。

GameSession

public static class GameSession
{
    public static LevelDefinition CurrentLevel;

    [RuntimeInitializeOnLoadMethod(
        SubsystemRegistration)]
    static void ResetOnPlay()
    {
        CurrentLevel = null;
    }
}

游戏启动时清空；场景重载时保留。真正的玩家进度仍需存档系统。

Maze 的选择

private void Awake()
{
    if (GameSession.CurrentLevel != null)
        level = GameSession.CurrentLevel;
    else
        GameSession.CurrentLevel = level;
}

首次进入使用 Inspector 初始关卡；后续场景载入使用 GameSession 当前关卡。

CanAdvance

State == Completed
&& maze != null
&& maze.CurrentLevel != null
&& maze.CurrentLevel.NextLevel != null

失败、暂停、未完成、没有下一关时都不能显示下一关入口。

Advance

GameSession.CurrentLevel = next;
Time.timeScale = 1f;
SceneManager.LoadScene(
    activeScene.buildIndex);

切换前恢复 timeScale；加载后由 Maze.Awake 读取新关卡。

UI

  • 完成 + 有下一关：显示“下一关”。
  • 完成 + 无下一关：隐藏按钮，显示 MAYA 收束台词。
  • 失败：隐藏下一关，保留重开。
  • 暂停：下一关不显示。

不同尺寸的关卡

sizeForHeight =
    level.Height * 0.5f + padding;
sizeForWidth =
    (level.Width * 0.5f + padding)
    / camera.aspect;

camera.orthographicSize =
    Mathf.Max(minimumSize,
        sizeForHeight,
        sizeForWidth);

正交相机要同时容纳地图的宽和高。关卡变尺寸后由 MazeCameraFitter 重新取景。

测试清单

  • 完成 FlowTest 后进入 Level_05。
  • Level_05 与顶部出口完整进入镜头。
  • Level_05 重开仍留在 Level_05。
  • Level_05 完成没有下一关按钮。
  • 失败不显示下一关。
  • 停止 Play 后恢复初始 Inspector 关卡。

报错急救

按钮不出现
NextLevel 未绑定，或 State 不是 Completed。
回到旧关
GameSession.CurrentLevel 没有在 reload 前更新。
重开跳错关
GameSession 没保存当前关，或 Maze.Awake 没读。
停止 Play 还保留
缺少 SubsystemRegistration 重置。
最后一关仍有按钮
CanAdvance 没检查 NextLevel。
新关卡显示不全
Camera 仍用固定正交尺寸；挂并绑定 MazeCameraFitter。
