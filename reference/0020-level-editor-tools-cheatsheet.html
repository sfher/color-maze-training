关卡编辑器工具

文本负责批量导入，编辑器窗口负责绘制，SerializedObject 负责安全写回，Validator 负责拒绝坏地图。

打印友好UnityEditorLevel Workflow

三层结构

LevelMapCodec
  string → string[]

LevelPainterWindow
  string[] → char[,]
  paint / sample / validate

SerializedObject
  char[,] → LevelDefinition.rows

解析、编辑、写资产分开，任何一层都能单独测试。

粘贴规则

  • CRLF、LF 都支持。
  • 每行首尾空白忽略。
  • 首尾空行可以删除。
  • 中间空行报错。
  • 行宽必须一致。
  • 只允许地图字符。

允许字符

.#SRBCME123456789

未知字符必须报错，不能静默当墙。

写入资产

SerializedObject so =
    new SerializedObject(level);

SerializedProperty rows =
    so.FindProperty("rows");

rows.arraySize = newRows.Length;
// 写每个 string
so.ApplyModifiedProperties();

写前记录 Undo，写后保存资产。

画笔状态

LevelDefinition level
char[,] cells
char brush = '#'
bool isDirty

左键 → 绘制
右键 → 取样
Apply → 写资产
Revert → 重读资产

坐标提醒

  • rows[0] 是地图顶部。
  • 游戏 y=0 是地图底部。
  • 起点固定为 x=1,y=1。
  • 网格 UI 绘制时最容易上下颠倒。

必做保护

  • 切换资产前检查未保存修改。
  • 缩小地图前确认。
  • 校验失败仍可保存 draft，但要标红。
  • 不要在 IMGUI 循环中直接改资产。

最小验收

  • 一次粘贴完整地图。
  • 点击绘制和右键取样。
  • Apply 后 Ctrl+Z 可撤销。
  • 坏地图指出行列。
  • 新建关卡无需改 YAML。
