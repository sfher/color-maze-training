Unity × C# 术语与速查

上课时遇到不懂的词，先查这里。课程里使用的术语以这张卡为准；它也会随着项目推进增补。

打印友好 随课更新 Unity 6 / C# 9+

编辑器地图

Hierarchy
当前场景里的对象树。谁是谁的子对象，在这里一目了然。
Scene
编辑视图。用来摆放对象、调整位置和查看 2D 图层关系。
Game
相机最终看到的画面。判断“玩家实际看到什么”只看这里。
Inspector
选中对象后显示其组件与属性。挂脚本、改数值都在这里。
Project
对应磁盘上的 Assets/。所有素材、场景、脚本都从这里进入工程。
Console
日志、警告与报错。红字优先处理，黄字记录待办。

对象模型

GameObject
场景中的实体容器，有名字、层级，本身不做事。
Component
给对象加能力的模块，例如渲染、碰撞、音频、脚本。
Transform
所有 GameObject 必有的组件，记录位置、旋转、缩放与父子关系。
MonoBehaviour
可挂到 GameObject 上的脚本基类，提供生命周期回调。
Sprite
2D 图像资源。SpriteRenderer 负责把它画到场景里。
Prefab
可复用的对象模板。改预制体会同步到所有实例，适合玩家、宝箱、格子。
ScriptableObject
不挂在场景里的数据资产，适合关卡配置、道具表、数值表。
.meta
Unity 为每个资产生成的引用信息。必须提交到 Git。
Library
Unity 自动生成的缓存目录。不要提交，删掉后重新打开工程会重建。

生命周期

挂载脚本后，Unity 按顺序调用这些方法。第一课只用到 Start，第二课会用 Update。

Awake()      // 对象创建时，最早
OnEnable()   // 每次启用时
Start()      // 启用后、第一帧前，只一次
Update()     // 每帧
OnDisable()  // 每次禁用时
OnDestroy()  // 销毁时

记忆 初始化放 Awake/Start，逐帧输入与动画放 Update。

网格数学

一维索引与二维坐标互转，是迷宫项目最常用的公式：

index = y * Width + x
x = index % Width      // 列
y = index / Width      // 行（整数除法）

字符串地图从上往下写，而 Unity 的 Y 轴向上，所以生成时常用：

int worldY = Height - 1 - (index / Width);

把 7 写在一个常量里，不要散落在代码各处。这叫 单一数据源（single source of truth）。

目录约定

路径用途进 Git？
Assets/Scenes/主场景与关卡场景是
Assets/Scripts/本项目自己的 C# 脚本是
Assets/Settings/URP 2D、输入等模板设置是
Assets/ThirdParty/外部插件与素材，尽量不改是
Packages/包依赖清单是
ProjectSettings/输入、渲染、构建设置是
docs/开发日志、设计文档是
Library/ Temp/ Logs/本地缓存与日志否

Git 提交类型

前缀用于例子
feat新功能feat: add player grid movement
fix修复缺陷fix: stop player entering walls
docs文档与日志docs: add lesson 01 devlog
refactor不改行为的重构refactor: extract level parser
test测试test: cover oxygen depletion
chore工程杂务chore: create Unity project

一次提交只做一件事；提交前先让工程能运行。这样出问题时，回退范围才小。

报错急救

CS1002
少了分号。看报错行号的上一行。
CS1513
少了右花括号 }。检查方法是否闭合。
CS0117
成员不存在。多半是拼写错误或 API 名称记错，查 Scripting API。
NullReference
引用了空对象。先确认 Inspector 里的引用是否拖上，再查初始化顺序。
洋红色方块
地图里有未识别字符，或 Sprite 材质缺失。前者查 ColorFor，后者查导入设置。
Play 按钮灰掉
工程有编译错误。打开 Console，双击第一条红字。
