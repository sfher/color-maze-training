音效事件速查

短音效绑定事件，不绑定帧。成功一次，反馈一次；背景音乐单独使用 AudioSource。

打印友好 AudioSource PlayOneShot

事件映射

Pickup       → pickup_material.ogg
ChestOpen    → chest_open.ogg
StoneBreak   → stone_break.ogg
Portal       → portal_enter.ogg
UiConfirm    → ui_confirm.ogg
LevelComplete→ level_complete.ogg
UiError      → ui_error.ogg
Damage       → damage.ogg

事件失败也要有边界：无材料出口用 UiError，不用过关音。

AudioManager

[SerializeField] private AudioSource source;
[SerializeField] private AudioClip pickup;

private void Play(AudioClip clip)
{
    if (clip == null || source == null)
        return;

    source.PlayOneShot(clip);
}

2D 音效：source.spatialBlend = 0f，playOnAwake = false。

调用点

if (maze.TryBreakStone(target))
    audio.PlayStoneBreak();

if (maze.TryOpenChest(cell))
    audio.PlayChestOpen();

if (maze.TryCollectMaterial(cell))
    audio.PlayPickup();

只在返回 true 的成功分支播放；不要放在 Update 或碰撞持续回调里。

流程事件

if (hasMaterial)
{
    SetState(Completed);
    audio.PlayLevelComplete();
}
else
{
    audio.PlayUiError();
    HintShown?.Invoke("还需要找到材料。");
}

死亡时播放 Damage；UI 确认音留给暂停/按钮。

Inspector 绑定

  • GameManager：Audio Source + AudioManager。
  • AudioManager：8 个 Clip 字段。
  • PlayerGridMover：Audio 字段拖 GameManager。
  • LevelFlowController：Audio 字段拖 GameManager。

Play vs PlayOneShot

Play()
适合背景音乐/持续音；会复用当前播放。
PlayOneShot()
适合短反馈，可叠加多个，不打断其他声音。
Loop
仅用于音乐/环境音；短事件音效不要循环。

测试清单

  • 8 个 Clip 字段均已绑定。
  • 每个事件只响一次。
  • 无材料出口播放错误音，不播放过关音。
  • 过关播放完成音，死亡播放伤害音。
  • AudioSource 不 Mute，AudioListener 存在。
  • 拾取音不会打断后续音乐。

报错急救

完全无声
检查 AudioListener、Mute、Volume、Game 视图音频开关。
部分无声
对应 Clip 为空，或事件没有进入成功分支。过关无声时先查 Level Complete 字段。
爆音/连续响
把调用移出 Update；每个成功事件调用一次。
音乐被打断
音乐与短音效不要共用 AudioSource。
Audio 为空
GameManager 没有拖入 PlayerGridMover/Flow 的 Audio 字段。
