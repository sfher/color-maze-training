宝箱与金币

宝箱是“一次性的运行时交互格”：进入时发奖励，然后变成地板。金币归玩家状态，关卡资产只保存宝箱模板。

打印友好 交互 资源所有权

开箱流程

进入格子
  → GetTileType == Chest ?
  → TryOpenChest(cell)
  → 奖励入账
  → Tile 改为 Floor
  → 更新 SpriteRenderer

进入时先验证，只有真的打开成功才发奖励；重复进入不会再次奖励。

一次性替换

public bool TryOpenChest(Vector2Int cell)
{
    return TryReplace(
        cell,
        TileType.Chest,
        TileType.Floor);
}

宝箱从 Chest 变成 Floor，所以下次 GetTileType 不再是 Chest。运行时副本不影响资产。

资源归谁

PlayerStats:
  Health
  Oxygen
  Bombs
  Coins

MazeBootstrapper:
  TileType[,]

PlayerGridMover:
  currentCell
  facing

金币是玩家状态，不应该存在关卡资产里；关卡资产只保存宝箱的位置。

本课奖励

private const int ChestCoins = 3;
private const int ChestBombs = 1;

stats.AddCoins(ChestCoins);
stats.AddBombs(ChestBombs);

原型阶段固定掉落，先验证资源循环；以后再做宝箱掉落表。

地板处理

if (maze.TryOpenChest(currentCell))
{
    stats.AddCoins(3);
    stats.AddBombs(1);
}

stats.ApplyTile(TileType.Floor);

宝箱开完就是地板，按地板规则恢复氧气；不要把宝箱当成岩浆或水。

HUD 顺序

生命: 3 / 3
氧气: 3 / 3
炸弹: 1
金币: 0

HUD 只读 PlayerStats；不要在 HUD 里修改金币。显示和状态分开，后面换正式 UI 时只换视图。

测试清单

  • 初始金币 0、炸弹 1。
  • 炸石头后炸弹变 0。
  • 进入宝箱后金币 3、炸弹 1。
  • 离开再回来不重复奖励。
  • 宝箱开完变地板。
  • 停止 Play 后资产里的 C 还在。

报错急救

洋红色
ColorFor 缺少 Chest，或 C 没映射成 Chest。
无奖励
进入格子后没调用 TryOpenChest，或当前格不是 Chest。
重复奖励
开箱后没有替换成 Floor。
金币不显示
HUD 没加 Coins 行，或盒子高度不够。
资产被改
写到了 LevelDefinition，而不是 _tiles 副本。
