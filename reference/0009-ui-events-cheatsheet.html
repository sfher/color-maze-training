UI 与事件

UI 是状态的观察者，不是状态的拥有者。状态变化发事件，界面收到后刷新；按钮只发出意图。

打印友好 Canvas / TMP 发布订阅

数据流

PlayerStats.StatsChanged
        ↓
GameHud.RefreshStats()
        ↓
StatsText.text

LevelFlowController.StateChanged
        ↓
GameHud.HandleStateChanged()
        ↓
EndPanel.SetActive(...)

UI 不修改生命、金币或材料；它只读取状态并显示。

Canvas 基础

  • Render Mode：Screen Space - Overlay。
  • Canvas Scaler：Scale With Screen Size。
  • Reference Resolution：1920 × 1080。
  • Match：0.5。
  • Canvas 下放 StatsPanel、EndPanel、HintText。

RectTransform

Anchor
相对父容器的位置。左上角状态栏用 Anchor Min/Max (0,1)。
Pivot
自身旋转和定位的基准点。左上角面板用 (0,1)。
Stretch
四边拉伸，适合面板内部的文字；设置边距而不是写死宽高。
Pos X/Y
相对锚点的偏移。左上角面板常见 Pos (32, -32)。

事件订阅

void Start()
{
    playerStats.StatsChanged += RefreshStats;
    flow.StateChanged += HandleStateChanged;
    flow.HintShown += ShowHint;
}

void OnDestroy()
{
    playerStats.StatsChanged -= RefreshStats;
    flow.StateChanged -= HandleStateChanged;
    flow.HintShown -= ShowHint;
}

订阅和取消订阅成对出现；避免对象销毁后还被事件引用。

按钮

restartButton.onClick.AddListener(flow.Restart);

// OnDestroy
restartButton.onClick.RemoveListener(flow.Restart);

按钮调用的是流程方法，不是直接改生命或重载场景。

提示计时

yield return new WaitForSecondsRealtime(2f);

使用 Realtime，暂停时提示也能正常计时；普通 WaitForSeconds 会受到 timeScale 影响。

UI 测试清单

  • 初始数值正确。
  • 受伤、耗氧、拾取、开箱后数值更新。
  • 没材料出口出现提示。
  • 完成和失败面板显示。
  • 按钮与 R 都能重开。
  • 调整窗口比例，布局不跑位。
  • Console 没有引用为空。

报错急救

两套 HUD
旧的 PlayerStats/LevelFlowController OnGUI 没删。
按钮无效
场景缺少 EventSystem 或 InputSystemUIInputModule。
文字看不清
TMP 字体材质、颜色、Canvas 排序或面板透明度。
数值不动
StatsChanged 没在状态修改后触发。
面板不显示
StateChanged 没触发，或 EndPanel 引用为空。
