事件、失败与重开

状态变化由所有者宣布，界面和音效订阅。订阅要成对取消，重开要让整个场景回到初始状态。

打印友好 C# event 场景重载

发布 / 订阅

// PlayerStats：发布者
public event System.Action Died;

if (Health == 0 && !_deathAnnounced)
{
    _deathAnnounced = true;
    Died?.Invoke();
}

// GameOverController：订阅者
playerStats.Died += HandlePlayerDied;

Died?.Invoke() 在没有订阅者时安全地什么也不做。

订阅生命周期

private void Start()
{
    playerStats.Died += HandlePlayerDied;
}

private void OnDestroy()
{
    if (playerStats != null)
        playerStats.Died -= HandlePlayerDied;
}

加号和减号必须成对。对象销毁后仍留在事件列表里，会形成悬空引用，也可能让回调重复执行。

一次性状态

private bool _deathAnnounced;

if (Health == 0 && !_deathAnnounced)
{
    _deathAnnounced = true;
    Died?.Invoke();
}

生命已经为 0 时再次扣血，不应该重复弹出“死亡”提示。用一个布尔值把一次性事件锁住。

场景重载

using UnityEngine.SceneManagement;

SceneManager.LoadScene(
    SceneManager.GetActiveScene().buildIndex);

场景必须在 File → Build Profiles → Scene List 中启用；编辑器里打开过不等于可加载。

失败覆盖层

GUI.depth = -10;
GUI.color = new Color(0, 0, 0, 0.68f);
GUI.DrawTexture(
    new Rect(0, 0, Screen.width, Screen.height),
    Texture2D.whiteTexture);
GUI.color = Color.white;

更小的 GUI.depth 画在更上层；临时覆盖层能盖住生命/氧气 HUD。

测试清单

  • 生命 3 → 0 时只弹一次失败提示。
  • 死亡后 WASD 不再移动。
  • 按 R 后 HUD 回到 3 / 3。
  • 按 R 后玩家回到起点。
  • 重开后再次死亡仍能触发提示。
  • Console 没有场景加载错误。

报错急救

没有提示
GameOverController 的 PlayerStats 引用为空，或没有订阅。
重复提示
缺少 _deathAnnounced 一次性保护。
R 无效
没有进入死亡状态，或 Game 视图没有焦点。
加载失败
Main 没有加入构建场景列表。
引用异常
订阅了已销毁对象；检查 OnDestroy 是否取消订阅。
