像素素材导入

先定需求再搜索；许可证不明不下载；PPU 等于贴图边长；Point 采样防糊；notices 带日期。

打印友好TextureImporterAsset Pipeline

导入设置表

Texture Type   Sprite (2D and UI)
Sprite Mode    Multiple / Single
Pixels Per Unit = 贴图边长 (16 / 32)
Filter Mode    Point (no filter)
Compression    None
Max Size       ≥ 原图边长

迷宫 1 格 = 1 世界单位，PPU = 边长时 1 sprite 恰好 1 格。

许可证判定

  • CC0 ✅ 无署名义务，记录来源即可。
  • CC-BY ⚠️ 可用，notices 记署名，发布物保留 credit。
  • OFL ✅ 字体；保留 LICENSE-OFL。
  • 未写明 ❌ 换素材，不猜。
  • itch.io 以随包文件 / 作者页为准。

目录约定

Assets/ThirdParty/Art/
  Kenney/
    <pack-name>/
      *.png
      License.txt   ← 必进仓库

png 与 .meta 成对提交，缺一不可。

切雪图

选中纹理 → Sprite Editor
  → Slice → Grid By Cell Size
  → 16×16（或 32×32）
  → Slice → Apply

切完在 Project 展开纹理，每个地块是一个子 Sprite。

notices 条目字段

ID | Asset | Author | Source
   | License | Date | Modified | Attribution
  • Date 必填，无日期难审计。
  • Modified 写明"选用地块切片，未修改原图"这类事实。
  • 同步更新 Local Files 与 License Texts 段。

故障速查

  • sprite 小到看不见 → PPU 还是默认 100。
  • 像素边缘发糊 → Filter 不是 Point。
  • 色块渗色 → Compression 不是 None。
  • 格子大小不一 → 混用了 16 与 32 的包。
  • 别人打开全丢引用 → 提交时漏了 .meta。
  • 场景变脏 → 只在临时场景冒烟，不保存。
