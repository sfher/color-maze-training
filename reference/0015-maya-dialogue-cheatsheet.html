MAYA 对话与逐字显示

对白是数据，推进是状态，逐字是表现。三者分开以后，新增台词、跳过动画和结束剧情都不会互相打架。

打印友好 IEnumerator 对话 UI

职责分工

LevelDefinition
  → MAYA 对白数据

MayaDialogueView
  → 当前句与逐字动画

GameHud
  → 输入与结算按钮

LevelFlowController
  → Completed / Failed 时机

台词不要写在 GameHud；GameHud 只决定什么时候把台词交给对话视图。

四个状态

string[] _lines
int _lineIndex
bool _lineIsComplete
bool IsShowing

数组保存内容，索引定位句子，两个布尔值分别管当前句和整段对话。

推荐推进规则

  1. 正在打字：补全当前一句。
  2. 当前句完整：进入下一句。
  3. 最后一句完整：结束对话。
  4. 对话结束：触发 Finished 事件。

快速点击最多补全当前句，不会一次略过整段剧情。

协程核心

visible += charactersPerSecond
    * Time.unscaledDeltaTime;

int count = Mathf.Min(
    line.Length,
    Mathf.FloorToInt(visible));

text = line.Substring(0, count);
yield return null;

每帧多显示一些字符，然后等到下一帧；不是后台线程。

完成分支

endPanel.SetActive(true);
restartButton.gameObject.SetActive(false);
nextLevelButton.gameObject.SetActive(false);
dialogue.Show(
    flow.CurrentLevel.CompletionDialogue);

先隐藏操作按钮，最后一句结束的 Finished 回调再开放可用操作。

失败分支

dialogue.HideImmediate();
restartButton.gameObject.SetActive(true);
nextLevelButton.gameObject.SetActive(false);
endHintText.text = "按 R 或按钮重开。";

失败不是剧情节点。不要播放通关对白，也不显示下一关。

结束分支

endTitleText.text = "关卡完成";
restartButton.gameObject.SetActive(true);
nextLevelButton.gameObject.SetActive(
    flow.CanAdvance);

对话结束后面板进入结算态，不能继续显示“通讯接入”。

文字区域

  • Vertical Alignment：Top。
  • 尺寸约 540 × 120。
  • 标题与正文之间留出间距。
  • 不要用 Bottom 对齐承载动态行数。

输入清单

  • 左键：推进对话。
  • 空格：推进对话。
  • Enter：推进对话。
  • R：已完成或失败时重开。
  • 只有 IsShowing 时读取推进输入。

验收清单

  • 第一句自动逐字出现。
  • 点击一次只补全当前句。
  • 再次输入才切换下一句。
  • 最后一句读完才出现按钮。
  • 失败不出现 MAYA 通关台词。
  • 重开和下一关后没有旧文字残留。

报错急救

文字空白
Body Text 未绑定，或关卡对白数组为空。
跳句太猛
打字中与完整句使用了同一条推进路径。
停在一半
跳过协程后没有立即补全当前句。
正文突然上移
动态文本使用 Bottom 对齐，新增提示行把正文向上顶。
按钮提前
Show 之前没有隐藏重开与下一关。
失败出对白
Failed 分支没有提前 return，落进了 Completed 逻辑。
