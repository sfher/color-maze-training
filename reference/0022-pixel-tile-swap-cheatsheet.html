像素地砖替换

内容进 ScriptableObject，代码只管规则；sprite 管长相，color 只管传送门染色；换格必须连 sprite 带白一起写。

打印友好SpriteRendererTileVisuals

渲染数据流

LevelDefinition 字符
  → TileType
  → TileVisuals.GetSprite(tile)
  → SpriteRenderer.sprite
  → Portal 例外：color = PortalColor(id)

白方块时代 color 是调色盘；像素时代 color 只染白螺旋。

TileVisuals 要点

  • 9 个 Sprite 字段：floor/wall/stone/water/lava/chest/material/exit/portalBase。
  • 资产放 Assets/Data/，名字 TileVisuals_Classic。
  • default 返回 floor，别返回 null。
  • 一套资产 = 一套主题；商店换皮 = 换引用。

TryReplace 坑

_renderers[x, y].sprite =
    visuals.GetSprite(replacement);
_renderers[x, y].color = Color.white;

color 是乘法 tint。只换 sprite 不清色，地板会带上石头灰或水蓝。

层级表

地砖   sortingOrder 0（默认）
炸弹   sortingOrder 5
玩家   sortingOrder 10

15b 之后仍然成立；新增渲染物先想清楚放哪层。

Player 场景设置

  • Sprite：player_default（Assets/Art/Player/）。
  • Color：纯白（旧黄色 tint 会让冒险者变黄）。
  • Order in Layer：10 不动。
  • 皮肤系列 8 张备用：orange/yellow/green/teal/blue/purple/rose。

尺寸为什么刚好

sprite 16px ÷ PPU 16 = 1 world unit = 迷宫 1 格

PPU 在贴图导入设置里；改 PPU 等于改格子大小，全项目统一。

不动的部分

  • PortalColor 两段紫（未知/已记忆）。
  • CellToLocal、相机、MazeCameraFitter。
  • CreateBombMarker 仍用白方块 + 缩放 0.5。

故障速查

  • 地图全白块 → Visuals 字段没绑（看 Console 报错）。
  • 地板带残色 → TryReplace 没重置 color。
  • 玩家变黄 → Player 的 Color 没归白。
  • 地砖糊/大小不对 → 导入设置被改（回参考卡 21）。
  • 传送门记忆失灵 → Start 里 portal 染色被误删。
