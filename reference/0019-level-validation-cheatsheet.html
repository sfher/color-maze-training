关卡校验

关卡进入内容目录前先检查起点、材料阈值、出口与传送门。地图矩形边界负责约束范围，外圈墙是可选项。

打印友好Editor ToolingContent QA

扫描

AssetDatabase.FindAssets(
    "t:LevelDefinition");

按类型查找，不依赖关卡放在哪个目录。

核心规则

  • 默认起点 `(1,1)` 可通行。
  • 地图 `M` 数量不少于 `requiredMaterials`。
  • 多余 `M` 合法，可用于后续辅助机制。
  • 出口恰好 1 个。
  • 每个传送门 ID 恰好 2 个。

过渡实现：`requiredMaterials` 尚未进入代码；当前 Validator 仍按材料恰好 1 个检查。迁移前，正式关卡不要把多余材料标成已通过。

可定位日志

Debug.LogWarning(
    $"关卡校验失败：{path}\n" +
    string.Join("\n", errors),
    level);

包含路径、原因和资产引用。

工具不能保证

  • 路径是否公平。
  • 难度是否合适。
  • 摄像机是否正确展示。
  • 材料是否真的可以到达。

这些仍要进入 Play 验证。

Editor 边界

  • 脚本放在 `Assets/Editor`。
  • 可以引用 `UnityEditor`。
  • 不会进入运行时构建。
  • 不要从运行时脚本引用 Editor 类。

发现错误后

  1. 点击 Console 定位资产。
  2. 只修一个错误。
  3. 再次运行校验。
  4. 最后进入 Play 验证可玩性。
