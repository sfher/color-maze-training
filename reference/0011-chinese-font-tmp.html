中文字体与 TMP Font Asset

TMP 显示的是 Font Asset 里的字形，不是系统字体。缺中文就缺字形；换字体资产才是修复。

打印友好 Fusion Pixel OFL 1.1

推荐字体

Fusion Pixel Font：泛中日韩像素字体，支持简体中文，提供 8/10/12px、等宽/比例模式。

  • 字体许可：SIL OFL 1.1。
  • 仓库代码：MIT。
  • 来源：GitHub TakWolf/fusion-pixel-font。
  • 版本：记录 release tag，例如 2026.10.16。

备用：Noto Sans SC（OFL，非像素）。Zpix 个人/教育免费，但商业产品要付费，不能默认当免费商用。

文件结构

Assets/
└── ThirdParty/
    └── Fonts/
        └── FusionPixel/
            ├── fusion-pixel-...ttf
            ├── OFL.txt
            ├── LICENSES/
            ├── FusionPixel SDF.asset
            └── ...atlas / material

字体、许可、TMP 资产、Atlas、Material 和 .meta 都要提交。

生成 Font Asset

  1. Window → TextMeshPro → Font Asset Creator。
  2. Source Font File：选中 TTF。
  3. Atlas Resolution：先 1024×1024。
  4. Padding：5。
  5. Atlas Population Mode：Dynamic；Creator 没此项时生成后在 Inspector 改。
  6. Character Set：Custom Characters 填当前 HUD 字符，或使用动态字形。
  7. Generate Font Atlas → 保存为 FusionPixel SDF.asset。

接入方式

Project Settings
  → TextMesh Pro
  → Settings
  → Fallback Font Assets
  → add FusionPixel SDF

也可以给每个 TMP Text 直接指定 Font Asset。全局 fallback 更不容易漏，但需要确认 fallback 真的生效。

字号

10px font → 20 / 30 / 40
12px font → 24 / 36 / 48

使用整数倍减少模糊。像素字体不是任意字号都清晰。

调试

仍有方框
Text 的 Font Asset 或 Material 不是同一套中文字体；Glyph Table 也可能缺字。
只有部分字
Atlas 已满时 Dynamic 不会自动扩容；开启 Multi Atlas，或降低 sampling point size 重新生成。
状态栏正常、结算方框
典型 Material 不匹配：Font Asset 换了，Material 仍是默认字体材质。
图集约 1013/1024
已满；Multi Atlas Textures 关闭时无法补字。开启后再重新加载字体资产。
字体模糊
字号不是 12/10 的整数倍，或 Canvas 缩放不匹配。
打包后缺字
动态字体的源字体/Atlas 未随项目打包；检查引用。
许可疑问
保留 OFL.txt 和 LICENSES/，按 OFL 要求署名/分发；不删原作者信息。
