内容商店核心

条目是资产、货架是资产、存档只有一个持有者；结算只挂在进入 Completed 的那一条路径上。

打印友好ScriptableObjectSave v2

三层结构

ContentEntry   一条商品
ContentCatalog 货架 + Resolve 查询
ProgressService 唯一存档持有者
  TryPurchase / Equip /
  SettleLevelComplete /
  IsLevelPlayable / DeleteSave

购买判定顺序

InvalidEntry    entry == null
AlreadyOwned    id 在 unlockedContentIds
NotEnoughCoins  coins < price
Purchased       扣币 + 解锁 + 写盘

每次成功修改都立即 Save 并发 Changed 事件。

存档 v2 新字段

equippedSkinId    默认 "skin-default"
equippedThemeId   默认 ""（= 默认视觉）
lastLevelId       读取存档的落点
completedLevelIds 首通判重 + 顺序解锁

v1 旧档缺失字段自动取默认值，无需迁移代码。

结算规则

通关: coins += 本局宝箱币
      首通: coins += 10
      completedLevelIds += 关名
      lastLevelId = 下一关 ?? 当前关
失败/重开: 不结算

关卡 id 用资产名（LevelDefinition.name）。

解锁判定

目录有条目 → 按购买状态
主线关卡 → 首关开
            通关 N 解锁 N+1（沿 NextLevel 链）

装备应用

  • Equip 写存档 + 同步 GameSession。
  • 皮肤：PlayerSkinApplier 进关换 sprite。
  • 主题：MazeBootstrapper 进关解析 _activeVisuals，下一局生效。

主题  深海 30 / 熔岩之心 50 / 赛博朋克 70
关卡  水世界 40 / 回廊 60

故障速查

  • 买了没解锁 → id 拼写不一致（存档记的是 entry.id）。
  • 金币忽多忽少 → 有第二处在 Save（只允许 ProgressService.Save）。
  • 首通重复发 → 结算被挂到了会重复触发的地方。
  • 皮肤不换 → PlayerSkinApplier 的 catalog/renderer 没绑。
  • 主题不生效 → 正常，下一局才生效。
