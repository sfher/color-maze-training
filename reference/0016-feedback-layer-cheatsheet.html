反馈层与界面动画

游戏事件描述“发生了什么”，反馈层决定“玩家看到和听到什么”。声音、颜色、时长可以调整，调用方的语义不该跟着散开。

打印友好 Facade UI Feedback

职责分工

PlayerGridMover
  → Damage / Pickup

GameFeedback
  → 声音 + 画面组合

AudioManager
  → 播放哪个 AudioClip

FeedbackFlash
  → 屏幕遮罩

调用方表达游戏事件，反馈层组合表现，低层音频继续只负责播放。

事件入口

feedback.Damage()
feedback.Pickup()
feedback.ChestOpened()
feedback.StoneBroken()
feedback.PortalUsed()
feedback.Error()

方法名使用事件语义，不叫 PlayRedFlash。

受击闪光

public void Damage()
{
    audio.PlayDamage();
    Flash(damageColor, 0.2f);
}

时长控制在 0.1–0.25 秒之间；它不是过场动画。

淡出协程

elapsed += Time.unscaledDeltaTime;
float progress =
    Mathf.Clamp01(elapsed / duration);

color.a = Mathf.Lerp(
    color.a, 0f, progress);

使用 unscaled 时间，UI 反馈不随 Time.timeScale 冻结。

连续触发

if (_flashRoutine != null)
{
    StopCoroutine(_flashRoutine);
}

_flashRoutine =
    StartCoroutine(FlashRoutine(...));

同一张遮罩只能有一个写入者，避免 alpha 闪烁和颜色残留。

全屏 Image

  • 四边 Anchor 拉伸。
  • Left/Top/Right/Bottom 为 0。
  • 初始 Alpha 为 0。
  • Raycast Target 关闭。
  • 位于 HUD 下方、游戏画面上方。

可访问性

  • 颜色不是唯一信息。
  • 生命和氧气数字仍然更新。
  • 声音提供同方向反馈。
  • 关闭 Screen Flash 仍可继续游戏。
  • 避免高频、长时、全屏强闪。

验收清单

  • 拾取与受击都有声音。
  • 两者使用不同颜色与时长。
  • 闪光结束回到透明。
  • 全屏遮罩不挡鼠标点击。
  • 连续反馈不叠加旧颜色。
  • 暂停不影响 UI 淡出。

报错急救

只剩声音
Screen Flash 未绑定，或遮罩 Alpha 一直为 0。
颜色不消失
协程结束后没有 ClearFlash。
点击失效
全屏 Image 的 Raycast Target 仍然开启。
颜色闪烁
多个协程同时写同一个 Graphic。
暂停冻结
动画误用了 scaled delta time。
