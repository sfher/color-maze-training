网格移动与输入速查

网格游戏的移动不是“每秒移动多少米”，而是“一次按键从一格走到相邻格”。这张卡记录最小可用的输入、坐标与验证顺序。

打印友好 Unity Input System 网格坐标

一帧内的数据流

Keyboard.current → ReadDirection() → TryMove() → IsWalkable() → CellToWorld() → transform.position

每一步只做一件事：读输入、算目标、验证、提交状态、更新显示。把“验证”放在“提交”之前，是网格移动最重要的顺序。

生命周期

Start()
对象启用后执行一次。适合绑定引用、设置初始格子。
Update()
每帧执行。适合读取输入、更新位置；不要在里面对整张地图做重活。
enabled = false
禁用组件，Update 不再执行；常用于引用缺失时保护后续逻辑。

新 Input System

using UnityEngine.InputSystem;

Keyboard keyboard = Keyboard.current;

if (keyboard == null)
{
    return Vector2Int.zero;
}

if (keyboard.wKey.wasPressedThisFrame)
{
    // 这一帧刚按下 W
}

区别 wasPressedThisFrame 只在按下瞬间为真；isPressed 在按住期间持续为真。

Vector2Int

Vector2Int.up      // (0, 1)
Vector2Int.down    // (0, -1)
Vector2Int.left    // (-1, 0)
Vector2Int.right   // (1, 0)
Vector2Int.zero    // (0, 0)

Vector2Int target = current + direction;
bool same = target == current;

网格坐标用整数，避免浮点误差；世界位置仍然用 Vector3。

格子 → 世界坐标

private Vector3 CellToLocal(Vector2Int cell)
{
    return new Vector3(
        cell.x - (Width - 1) * 0.5f,
        cell.y - (Height - 1) * 0.5f,
        0f);
}

public Vector3 CellToWorld(Vector2Int cell)
{
    return transform.TransformPoint(CellToLocal(cell));
}

TransformPoint 会把 Maze 根对象的位置、旋转和缩放一起算进去；以后移动 Maze 时，玩家仍会对齐。

移动验证顺序

private void TryMove(Vector2Int direction)
{
    Vector2Int target = currentCell + direction;

    if (!maze.IsWalkable(target))
    {
        return;
    }

    currentCell = target;
    transform.position = maze.CellToWorld(currentCell);
}

如果先改 currentCell 再验证，失败时还得回滚；先验证可以少一条失败路径。

Inspector 引用

[SerializeField]
private MazeBootstrapper maze;

[SerializeField] 让私有字段出现在 Inspector。运行时为空会抛 NullReferenceException，所以在 Start 里先检查并给出明确报错。

报错急救

没反应
先点 Game 视图；再检查 Active Input Handling 与 Console。
连续移动
把 isPressed 改为 wasPressedThisFrame。
空引用
Maze 字段没有拖引用；拖挂了 MazeBootstrapper 的对象。
被盖住
提高 Player 的 Sorting Order，例如 10。
撞墙能走
检查 TryMove 是否真的调用了 IsWalkable。
