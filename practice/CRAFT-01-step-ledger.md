# CRAFT-01 · 步数账本

> 匠人块协议：**空白起步**，只看本文件。不查 solutions、不翻工程里同类代码。卡住超过 5 分钟 → 停下，告诉我卡在第几条规格；写完 → 把文件发我点评。预计 15–20 分钟。

## 游戏背景

每关有步数上限（`StepLimit`）。只有**成功移动**才消耗 1 步（撞墙不计步——那是调用方的责任，账本只管记账）。最后一步走完仍未通关 → 步数耗尽失败。这个零件就是游戏里的 `LevelRunState`，这次由你从零写。

## 规格

写一个类 `StepLedger`（纯 C#，不 using 任何 Unity 东西）：

| 成员 | 形态 | 行为 |
|---|---|---|
| 构造函数 | `new StepLedger(int limit)` | 记住上限；可以假设 `limit >= 1`（在注释里写下这个假设） |
| `Remaining` | 只读属性 `int` | 剩余可走步数，初始 = limit，永远不为负 |
| `IsExhausted` | 只读属性 `bool` | 剩余为 0 即耗尽 |
| `TrySpendStep()` | 方法 `bool` | 还有剩余：扣 1 步返回 `true`；已耗尽：什么都不改，返回 `false` |

设计提示（不是答案）：三个成员里有一个是"账本真正存的数据"，另外两个是从它推算出来的——想清楚哪个是哪个，代码会非常短。
